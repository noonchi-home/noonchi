# React 화면 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 대시보드와 설정 화면을 React+TypeScript로 옮기고, 3D 트윈을 화면 전체 배경으로 깔고 그 위에 가전 상태 말풍선을 항상 띄운다.

**Architecture:** 새 `ui/` 패키지(Vite 다중 페이지: `/`, `/setup/`)가 화면을 맡고, 서버는 빌드 결과 `ui/dist`를 지금처럼 정적 파일로 내준다. 3D는 twin-studio 뷰어를 같은 출처 iframe(`/twin/viewer/?live=auto&embed=1`)으로 띄우고, React가 `iframe.contentWindow.aptViewer`(카메라·노드·THREE)를 직접 읽어 말풍선 위치를 계산한다. twin-studio 저장소는 고치지 않는다. 서버와 화면이 주고받는 메시지 타입은 `src/contract/`의 순수 타입 파일 하나에서만 정의한다.

**Tech Stack:** React 19, TypeScript, Vite, Tailwind CSS 4, shadcn 규칙(`cn`), 21st.dev 부품(MCP `get_component`로 코드를 받아 `ui/src/components/ui/`에 둔다), Vitest + jsdom + Testing Library.

**Spec:** 사용자 요청(2026-11-06): 「프론트 react+typescript로 하자」, 「가전 상태 같은 거는 실제 트윈 화면 위에 말풍선으로 항상」. 화면 구조는 비교 페이지 https://claude.ai/artifact/3d2Ubn7zYgUPodK4U7cdKn 의 A(트윈 배경 + 떠 있는 유리 패널).

## Global Constraints

- 화면 글은 사용자가 할 일과 지금 상태만 쓴다. 화살표 흐름·괄호 설명·60자 넘는 덩어리·구현 이름·설명 칸을 넣지 않는다(`CLAUDE.md` 규칙 표, `npm run lint`).
- twin-studio 저장소(`../twin-studio`)는 고치지 않는다. 뷰어는 `window.aptViewer`로만 다룬다.
- 3D 객체는 반드시 뷰어의 `aptViewer.THREE`로 만든다(`three`를 따로 불러 섞지 않는다).
- 폰 화면(`web/phone/`)은 이 계획에서 옮기지 않는다. 폰 서버(8210)는 그대로 `web/phone/`을 내준다.
- 대시보드는 127.0.0.1에만 묶고, WebSocket·POST는 로컬 출처만 받는다(`src/server/app.ts` `LOCAL_ORIGIN`). 개발 서버는 5173에서 프록시로 붙는다.
- `ui/`는 자기 `node_modules`를 쓴다. 루트 `node_modules`(본 작업 폴더로 이어진 연결)에 화면 패키지를 깔지 않는다.
- ThinQ 실제 제어 금지, 기기 명령은 지금처럼 허브·정책을 거친다. 키·토큰을 출력하지 않는다.
- 커밋은 사용자가 허락한 뒤에만 한다. `git add`는 파일 경로를 하나씩 적는다.

`ui/src/lib/messages.ts`
```ts
import type { ServerMessage } from "../../../src/contract/events.ts";

const KNOWN = new Set<ServerMessage["type"]>(["hello", "state", "agent", "brain", "photo", "focus", "eye"]);

export function parseMessage(text: string): ServerMessage | null {
  try {
    const m = JSON.parse(text) as { type?: unknown };
    return typeof m?.type === "string" && KNOWN.has(m.type as ServerMessage["type"]) ? (m as ServerMessage) : null;
  } catch {
    return null;
  }
}
```

`ui/src/lib/use-events.ts`
```ts
import { useEffect, useRef } from "react";
import type { ServerMessage } from "../../../src/contract/events.ts";
import { parseMessage } from "./messages";

/** /events에 붙어 메시지마다 onMessage를 부른다. 끊기면 2초 뒤 다시 붙는다. */
export function useEvents(onMessage: (m: ServerMessage) => void, onOpen?: (open: boolean) => void) {
  const handler = useRef(onMessage);
  handler.current = onMessage;
  useEffect(() => {
    let ws: WebSocket | null = null;
    let timer: ReturnType<typeof setTimeout> | undefined;
    let closed = false;
    const connect = () => {
      ws = new WebSocket(`${location.protocol === "https:" ? "wss" : "ws"}://${location.host}/events`);
      ws.onopen = () => onOpen?.(true);
      ws.onmessage = (e) => { const m = parseMessage(String(e.data)); if (m) handler.current(m); };
      ws.onclose = () => { onOpen?.(false); if (!closed) timer = setTimeout(connect, 2000); };
    };
    connect();
    return () => { closed = true; clearTimeout(timer); ws?.close(); };
  }, [onOpen]);
}
```

```ts
export async function api<T>(path: string, body?: unknown): Promise<{ ok: boolean; status: number; json: T | null }> {
  const res = await fetch(path, body === undefined ? undefined : { method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify(body) });
```

`ui/src/twin/viewer.ts`
```ts
import { createContext, useContext } from "react";
import type * as THREE_NS from "three";

/** twin-studio 뷰어(window.aptViewer) 중 화면이 쓰는 부분. 원본: ../twin-studio/apartment/viewer/main.mjs window.aptViewer */
export interface AptViewer {
  THREE: typeof THREE_NS;
  scene: THREE_NS.Scene;
  camera: THREE_NS.PerspectiveCamera;
  renderer: THREE_NS.WebGLRenderer;
  ready: Promise<unknown>;
  node(id: string): THREE_NS.Object3D | null;
  hidden(id: string): boolean | null;
  setBadges(on: boolean): void;
  setFocus(focus: unknown): void;
  renderNow(): void;
}

export async function waitForViewer(win: Window, timeoutMs = 15000): Promise<AptViewer> {
  const end = Date.now() + timeoutMs;
  for (;;) {
    const v = (win as Window & { aptViewer?: AptViewer }).aptViewer;
    if (v) { await v.ready; return v; }
    if (Date.now() > end) throw new Error("3D 트윈을 찾을 수 없어요.");
    await new Promise((r) => setTimeout(r, 100));
  }
}

export const ViewerContext = createContext<AptViewer | null>(null);
export const useViewer = () => useContext(ViewerContext);
```

```ts
/** 열 우선 4×4 viewProj로 월드 점을 화면 픽셀로. 카메라 뒤이거나 화면 밖(여유 5%)이면 visible=false. */
export function projectPoint(m: ArrayLike<number>, [x, y, z]: [number, number, number], w: number, h: number) {
  const cx = m[0] * x + m[4] * y + m[8] * z + m[12];
  const cy = m[1] * x + m[5] * y + m[9] * z + m[13];
  const cw = m[3] * x + m[7] * y + m[11] * z + m[15];
  if (cw <= 0) return { x: 0, y: 0, visible: false };
  const nx = cx / cw;
  const ny = cy / cw;
  const visible = Math.abs(nx) <= 1.05 && Math.abs(ny) <= 1.05;
  return { x: ((nx + 1) / 2) * w, y: ((1 - ny) / 2) * h, visible };
}
```

```ts
import type { AptViewer } from "./viewer";

/** 기기 노드 경계 상자의 위쪽 가운데(말풍선 꼬리가 닿는 곳). 노드가 없으면 null. */
export function deviceAnchor(v: AptViewer, id: string): [number, number, number] | null {
  const node = v.node(id);
  if (!node) return null;
  const box = new v.THREE.Box3().setFromObject(node);
  if (box.isEmpty()) return null;
  const c = box.getCenter(new v.THREE.Vector3());
  return [c.x, box.max.y + 0.08, c.z];
}
```

`ui/src/twin/use-anchors.ts`
```ts
import { useEffect, useState } from "react";
import { deviceAnchor } from "./anchors";
import { projectPoint } from "./project";
import { useViewer } from "./viewer";

export type ScreenPoint = { x: number; y: number; visible: boolean };

/** 매 프레임 기기 id들의 화면 좌표. 숨겨진 노드(방 초점 등)는 visible=false. 바뀐 게 없으면 다시 그리지 않는다. */
export function useAnchors(ids: string[]) {
  const v = useViewer();
  const [points, setPoints] = useState<Map<string, ScreenPoint>>(new Map());
  useEffect(() => {
    if (!v) return;
    const world = new Map(ids.map((id) => [id, deviceAnchor(v, id)]));
    const viewProj = new v.THREE.Matrix4();
    let raf = 0;
    let last = "";
    const tick = () => {
      const { clientWidth: w, clientHeight: h } = v.renderer.domElement;
      viewProj.multiplyMatrices(v.camera.projectionMatrix, v.camera.matrixWorldInverse);
      const next = new Map<string, ScreenPoint>();
      for (const [id, p] of world) {
        if (!p || v.hidden(id)) { next.set(id, { x: 0, y: 0, visible: false }); continue; }
        const s = projectPoint(viewProj.elements, p, w, h);
        next.set(id, { x: Math.round(s.x), y: Math.round(s.y), visible: s.visible });
      }
      const key = JSON.stringify([...next]);
      if (key !== last) { last = key; setPoints(next); }
      raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, [v, ids.join(",")]);
  return points;
}
```

```ts
import type { DeviceView } from "../../../src/contract/events.ts";

const ATTR_TEXT: Record<string, Record<string, string>> = {
  power: { on: "켜짐", off: "꺼짐" }, running: { true: "동작 중", false: "멈춤" },
  lock: { locked: "잠김", unlocked: "잠금 해제" }, door: { open: "문 열림", closed: "문 닫힘" },
  curtain: { open: "열림", closed: "닫힘" }, blind: { open: "열림", closed: "닫힘" },
  faucet: { on: "물 나옴", off: "물 잠김" }, water: { on: "물 나옴", off: "물 잠김" },
  heating: { on: "난방 켜짐", off: "난방 꺼짐" }, charging: { on: "충전 중", off: "충전 안 함" },
};
const ACTIVE: Record<string, unknown> = { power: "on", running: true, lock: "unlocked", door: "open", curtain: "closed", blind: "closed", faucet: "on", water: "on", heating: "on", charging: "on" };
const ALERT = new Set(["door", "lock"]);
const MODES: Record<string, string> = { cool: "냉방", heat: "난방", auto: "자동", dry: "제습", fan: "송풍" };
const FANS: Record<string, string> = { low: "약", medium: "중", high: "강", auto: "자동" };

export type Tone = "on" | "off" | "alert" | "unknown";

export function deviceSummary(d: DeviceView): { title: string; line: string; tone: Tone } {
  const s = d.state;
  if (s?.signal === "none") return { title: d.label, line: "모름", tone: "unknown" };
  const twin = s?.twin ?? {};
  const m = (s?.matter ?? {}) as Record<string, unknown>;
  const parts: string[] = [];
  let on = false;
  let alert = s?.online === false;
  for (const [attr, v] of Object.entries(twin)) {
    const text = ATTR_TEXT[attr]?.[String(v)];
    if (!text) continue;
    parts.push(text);
    if (ACTIVE[attr] === v && attr !== "curtain" && attr !== "blind") { on = true; if (ALERT.has(attr)) alert = true; }
  }
  if (d.kind === "light" && m.onOff && typeof m.level === "number") parts.push(`밝기 ${m.level}%`);
  if (d.kind === "speaker" && typeof m.level === "number") parts.push(`음량 ${m.level}%`);
  if ((d.kind === "aircon" && m.onOff) || (d.kind === "thermostat" && m.systemMode !== "off")) {
    if (d.kind === "aircon" && typeof m.systemMode === "string" && MODES[m.systemMode]) parts.push(MODES[m.systemMode]);
    if (typeof m.setpointC === "number") parts.push(`${m.setpointC}°C`);
  }
  if (["purifier", "fan", "hood"].includes(d.kind) && typeof m.fanMode === "string" && m.fanMode !== "off") parts.push(`바람 ${FANS[m.fanMode] ?? m.fanMode}`);
  if (s?.online === false) parts.push("오프라인");
  return { title: d.label, line: parts.join(" · ") || "꺼짐", tone: alert ? "alert" : on ? "on" : "off" };
}
```

```ts
import { useCallback, useEffect, useState } from "react";
import type { DeviceView, ServerMessage } from "../../../src/contract/events.ts";
import { api } from "./api";

export function useDevices() {
  const [devices, setDevices] = useState<Map<string, DeviceView>>(new Map());
  const load = useCallback(async () => {
    const r = await api<{ devices: DeviceView[] }>("/api/devices");
    if (r.json) setDevices(new Map(r.json.devices.map((d) => [d.id, d])));
  }, []);
  useEffect(() => { void load(); }, [load]);
  const apply = useCallback((m: ServerMessage) => {
    if (m.type !== "state") return;
    setDevices((prev) => {
      const d = prev.get(m.state.id);
      if (!d) return prev;
      const next = new Map(prev);
      next.set(d.id, { ...d, state: m.state });
      return next;
    });
  }, []);
  return { devices, apply, reload: load };
}
```

```ts
export function pickPhoneUrl(urls: string[]) {
```
