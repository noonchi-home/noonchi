## 1. 레퍼런스의 구체 값

### 1.1 카메라
| 항목 | 값 | 근거 |
|---|---|---|
| 투영 | 약한 원근(망원), 세로선은 똑바로 보정한 2점 투시 | 세로선 기울기 89.9~90.1°(화면 6곳). 같은 방향 수평선이 먼 쪽 28.7°/32.7°, 가까운 쪽 34.8°/39.1°로 모임 |
| 고도각 | 중앙 약 **42°** (먼 쪽 36° ~ 가까운 쪽 48°) | 두 축 화면 기울기로 계산(tanα₁·tanα₂ = sin²e). 발코니 둥근 탁자 타원비 0.70~0.76 → 아래쪽 44~49° |
| 방위각 | 평면 축에서 약 **45~47°**(거의 대각선) | 두 축 기울기 비율 |
| 화면비 | 1.14:1 | |

### 1.2 구도·여백
- 집 외곽 상자가 **화면 네 변에 닿아요(여백 0, 꽉 자름)**. 집이 차지하는 픽셀 51.6%.
- 대각선 45° 배치라 모서리 네 곳은 빈 배경이에요.

### 1.3 배경
- **단색 #BDBDBD**(중간 밝기 무채색), 그라데이션·비네트 없음.
- 집 바깥 배경에 **그림자가 전혀 없어요**(집 가장자리 2~80 px 밖이 모두 #BDBDBD). 잘라낸 모형처럼 떠 있음.
- 집 아래 바닥판 옆면이 회색 띠(#848587, 0.15~0.2 m 두께로 보임)로 보여요.

### 1.4 벽 높이와 절개 방식
- 뒤쪽 바깥벽(화면 위 왼쪽·위 오른쪽 변): **천장 높이 그대로**, 창이 보임.
- 앞쪽 바깥벽·대부분의 안벽: **약 1.0~1.2 m 높이로 자름**(확인 필요: 정확한 값은 못 잼). 뒤쪽 욕실 칸막이처럼 짧은 안벽 몇 개만 높게 둠(작가가 손으로 고른 것).
- 앞쪽 발코니·큰 창: 투명 유리 난간 + 검은 기둥으로 낮게 자름.
- 문짝 없음(문 자리는 빈 통로).

### 1.5 벽 윗면(캡)
- **모든 벽 윗면이 같은 진회색 #5D5B5C**(범위 #575558~#636164), 높은 뒤쪽 벽 윗면도 같음 → 평면도 선처럼 구조가 한눈에 읽힘.
- 조명에 따라 색이 거의 안 바뀜(평평한 단색).
- 두께: 실제 벽 두께 그대로(바깥벽·안벽 캡 폭이 화면에서 15~18 px로 비슷).
- 바깥 모서리에 1~2 px 밝은 선(#DCDCDC~#EDEDED): 모서리를 살짝 둥글린 효과. 캡 안쪽 모서리에는 어두운 선(#413831).

### 1.6 벽 재질
| 재질 | 보이는 색 | 쓰인 곳 |
|---|---|---|
| 흰 무광 페인트 | 밝은 면 #E9E9E9~#F0F0F0 | 대부분 벽 |
| 나무 패널(월넛·티크 중간 톤, 세로 결) | #93705C~#A27F69 | 침대 뒤 벽, 칸막이 바깥면 |
| 마이크로시멘트(회갈색) | #B1A79E | 욕실 벽 |
| 바깥 외벽면 | 밝은 면 #D2CECB / 그늘 면 #808185~#888888 | 집 바깥쪽 |
| 창 | 틀 검정 #0C0C0C(가늘게), 유리 회색→흰색(#7E8285→#EDEDED) | 뒤쪽 벽 |

### 1.7 바닥 재질(방별)
| 공간 | 재질 | 보이는 색 |
|---|---|---|
| 침실·드레스룸 | 밝은 오크 마루, 결 대비 약함 | #CAA789~#D2B497 |
| 거실·식당·주방·복도 | 큰 판 밝은 포세린 타일, 줄눈 거의 안 보임, 살짝 광택 | 밝은 곳 #DCD7D3~#EDECE6, 그늘 #C9C4BE |
| 욕실 | 밝은 회색 타일·마이크로시멘트 | #D5D2CD 근처 |
| 발코니·테라스 | 밝은 회갈색 석재 타일, 줄눈 보임 | #C8BFB6~#D2CECB |
| 러그 | 미색, 결 무늬 | #ECE7E3 |

### 1.8 조명
- **주광 방향: 화면 오른쪽 위(먼 쪽)에서.** 화면 오른쪽 아래를 보는 벽면이 왼쪽 아래를 보는 면보다 약 1.4배 밝음(BBQ 굴뚝: #D7D2CE 대 #979795).
- **그림자: 짧고 아주 부드러움.** 가구 그림자는 화면 왼쪽 아래로 살짝, 바닥이 10~20%만 어두워짐. 경계가 흐림(큰 면광원). 주광 고도는 높음(약 60°, 55~70°).
- **간접광이 강함**: 그늘 쪽 실내 흰 벽도 #EDEDED로 밝음. 그늘/양지 비율 약 0.65~0.75.
- 노출: 밝고 하얀 톤. 밝은 쪽 99.5% 지점 L=242, 하얗게 날아간 픽셀 0.08%(거의 없음).
- 블룸·비네트·반사 효과 없음. 색온도 중립~살짝 따뜻.

### 1.9 AO
- 가구 바로 밑 접촉선: 아주 진함(L 40~60).
- 벽-바닥 모서리: 약함(5~10% 어두워짐).
- 쿠션 사이·수납장 틈: 진한 선.
- 0.3 m 넘게 떨어진 곳은 영향 없음.

### 1.10 소품 밀도
- 방마다 꽉 찬 스타일링: 침대마다 베개 4~7개 + 담요, 협탁·스탠드, 러그, 벽 그림, 방마다 화분 1개 이상(전체 약 12개), 식탁 12인 식기, 드레스룸 옷·신발·가방, 욕실 수건·소품.
- 보이는 물체 약 200~300개로 추정.

## 3. 실시간(내장 Radeon)에서 따라갈 수 있는 범위

이 PC: Ryzen 7 7730U 내장 그래픽(Vega 8급, 전용 2 GB). 비용 숫자는 추정이라 성능 측정에서 확인 필요.

| 요소 | 실시간으로 | 방법 |
|---|---|---|
| 구도·여백·배경·캡·벽 절개 | 그대로 가능 | 카메라 맞추기, 캡은 빛 안 받는 단색 재질 |
| 재질 색·거칠기·노멀 | 거의 가능 | PBR 텍스처(바닥 2K, 가구 1K, 소품 512, KTX2) |
| 부드러운 주광 그림자 | 일부 | 그림자 지도 2048~4096, 정적이라 한 번만 그리고 상태 바뀔 때만 다시. 큰 면광원 수준의 넓은 흐림은 못 따라감 |
| 간접광(실내가 밝게 차는 느낌) | 못 함 | **라이트맵 베이크** + 환경광·반구광으로 보충 |
| 접촉 AO | 비쌈 | **정적 물체는 AO 베이크**, GTAO는 High에서만(움직이는 문·CLOiD용) |
| 천 주름·식물 | 예산 안에서 일부 | 식물 8개 이하, 개당 3만 삼각형 이하, 잎은 alphaTest(블렌딩 금지) |
| 유리·타일 광택 | 가능 | 환경맵 반사만(SSR 안 씀) |
| 망원 원근 | 안 따라감 | 직교 유지 |

### 베이크가 필요한 것
1. **구조물(바닥·벽·바닥판) 간접광 라이트맵**: Blender Cycles로 「천장 없음 + 전체 화면 절개 상태」에서 간접광만 굽기. 주광(직접광)은 실시간으로 둠 → 문·상태 변화 그림자가 맞음. 아틀라스 2K × 2장(바닥 1, 벽 1), 바닥 약 2 cm/텍셀.
2. **가구·가전 자체 AO**: 에셋 빌드 때 에셋마다 한 번(배치와 상관없음).
3. **가구가 바닥에 남기는 접촉 그림자**: High는 바닥 라이트맵에 포함(배치 바뀌면 다시 굽기), Balanced·Performance는 가구 밑 흐린 그림자 판(투명 PNG 한 장).
4. 필요 작업: 모든 GLB에 두 번째 UV(라이트맵용) 만들기. three.js에서는 `texture.channel = 1`로 연결(설치 버전 확인 필요). 라이트맵을 쓰면 환경광의 확산 세기를 그만큼 낮춤(이중으로 밝아짐 방지).
5. 방 화면에서 벽을 세우면 라이트맵(전체 화면 기준)과 조금 어긋남 → 허용(직접광 그림자는 실시간이라 맞음).

## 4. 시각 스펙 표(토큰)

색은 sRGB hex. 「목표 화면색」은 렌더 결과를 재서 맞출 값, 「albedo」는 재질 바탕색 시작값.

### 4.1 카메라·구도·배경
| 토큰 | 값 | 비고 |
|---|---|---|
| `camera.projection` | orthographic | 스펙 5.1 |
| `camera.elevationDeg` | **42** (사용자 회전 허용 30~60) | 레퍼런스 중앙값 |
| `camera.azimuthDeg` | 45 (평면 축 대각선, 한양목련은 남동→북서 유지) | 회전 허용 ±45° |
| `fit.overviewMargin` | 각 변 3% | 잘린 벽은 잘린 높이, 세운 벽만 천장 높이로 맞춤 |
| `fit.roomMargin` | 각 변 8% | |
| `fit.objectMargin` | 각 변 15% | 극단 확대 방지 |
| `bg.color` | **#BDBDBD** | twin-home 밝은 화면과 어울림 확인 필요(대안 #C8C8C6) |
