# World State 낱말 표 계획

**목표:** FSM(박석준·김준형, 수요일까지)이 집 안 대부분의 상황을 계기로 쓸 수 있게 World State가 보는 낱말을 넓힌다. 모든 계기는 World State로 볼 수 있어야 한다. 계획 단계의 끝난 조건·기다리기 조건도 같은 키로만 쓴다.

**구조:** 낱말 표 하나(`src/world/vocab.ts`)가 원본이다. 감지기 거름(`src/brain/detector.ts` `COCO_LABELS`), VLM 스키마 enum·프롬프트(`src/observe/scene.ts`), World State 면·신뢰도·지금만 맞는 면·관절 자세(`src/world/state.ts`), 화면·관찰 텍스트 글(`src/world/labels.ts`), 가전 상태·사건(`src/world/relations.ts`), 계획 조건(`src/world/conditions.ts`), 대시보드 상자 이름(`ui/src/dashboard/words.ts`), 문서 표(`docs/world-vocabulary.md`, `scripts/world-vocab-doc.ts`)가 거기서 나온다. 보는 방법·계기 예는 `src/world/vocab-doc.ts`(같은 키의 Record 타입).

**출처:** 사용자 「우리가 그냥 만들어도돼 초안이 아니라 herdr agent list 피드백도 받아가면서 제대로 만들어」, 「worldstate는 한정된 상태중에 고르는거야? 만약 그렇다면 집안에서 일어날수있는 대부분의 상황을 state로 넣어야해」, 「state안에서 기다려야되는것도 action으로 넣을거지?」(기다리기 행동의 조건 값).

## 정한 것

- 종류: COCO 80종 가운데 물건 30종(유리컵은 컵), 가전 설비 6종(TV·냉장고·전자레인지·오븐·토스터·싱크대: 방마다 보이는 상태만), 가구 10종은 거른다(트윈에 있음). 개·고양이는 1.5m 안이면 같은 동물.
- 신뢰도: 사람 0.5·컵·병·그릇 0.4(실제 프레임으로 맞춤), 작은 식기·리모컨·여행 가방 0.45, 음식·드문 물건·동물·가전 설비 0.5(아직 실제 프레임으로 맞추지 않음).
- 사실 면: 자리 12·안 내용 3·열림 2·쓰는 중 2·화면 2·자세 3·들고 있음 1·하는 일 21·순간 동작 5. 종류마다 붙는 면이 정해져 있고, 맞지 않는 VLM 값은 버린다.
- 사람: 수, 발이 보인 바닥 자리와 방(눈의 방으로 대신하지 않음), 가까운 가전, 손에 있는 물건.
- 가전: 모든 가전의 상태 키(트윈 속성 값)와 사건(그 상태가 됨), 냉장고·현관문 문이 1분 넘게 열림(판단 타이머가 `tick`).
- 관찰 텍스트: `[지속]` 사람 줄에 수·방·가까이·자세·하는 일, 가전 설비 줄, 가전 줄(켜짐류·관련 가전·10분 안에 바뀐 것), `[때]` 날짜·요일·하루 때.
- VLM 출력 모양은 그대로(`observations: [{object_id, state}]`, `summary`), enum과 프롬프트만 낱말 표에서 만든다.
