> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**목표:** 한양목련 180B 실제 대시보드(6판)를 three.js 트윈(구운 빛 r2b)으로 만들고 실제 자료(폰 영상·YOLO 상자·PAM 판단·계획 단계·클로이드 눈)를 붙인다. 컵 치우기가 실제 집 자료로 4단계 다 돈다.

**구조:** 빛 굽기 스파이크를 `ui/src/twin3d/`로 키운다. 구운 GLB를 고정 정사영 카메라(방위 −45°, 고도 45°)로 그리고, 카메라는 확대·이동만 하며, 바뀔 때만 그린다. 대시보드는 시안 A 6판(`feat/dashboard-proto` a66bd22)을 `ui/src/dashboard/`로 옮기고, 시안의 집 그림 자리에 three.js 캔버스를 둔다. 경로·클로이드·기기 말풍선·어둡게 한 방은 시안처럼 화면 위 SVG·HTML 판에 그린다. 정사영이라 카메라 확대·이동은 판의 2D 변환과 같고, 판은 3D 카메라와 같은 값으로 그림마다 움직인다. 서버는 도면 설비(싱크대)·YOLO 상자·말풍선 글·승인 규칙을 더한다.

**따르는 결정:** 사용자 결정 1~9·승인 규칙·도면 설비 `docs/superpowers/specs/2026-11-09-twin3d-fast.md`, 대시보드 6판 `docs/superpowers/specs/2026-11-09-dashboard-6.md`, 결정 표 `2026-11-06-twin3d-decisions.md` D3·D29·D35·D36·D37·D38·D39. 계약·데이터 연결의 바탕은 긴 계획 `2026-11-06-twin3d.md`(공통 계약, Task 25~37)이고, 이 문서가 가리키는 부분만 쓴다.

## Global Constraints

- 판 고정: `three@0.187.0`, `@types/three@0.187.0`. R3F·EffectComposer·camera-controls는 쓰지 않는다.
- 렌더러: `antialias: true`(MSAA), `stencil: true`, `preserveDrawingBuffer: false`, 그림자 지도 없음, 톤매핑 AgX High Contrast 흉내(스파이크 그대로), 노출 1.0, 배경 `#BDBDBD`, DPR `min(devicePixelRatio, 2)`.
- 카메라는 구운 보기 하나(방위 −45°, 고도 45°, 그림 계획 카메라 값)다. 바뀌는 것은 확대·이동뿐이고 벽 보기는 처음 한 번만 정한다.
- 바뀔 때만 그린다: 카메라 움직임·상태·배치·창 크기·첫 그림. 멈춰 있으면 그리지 않는다(돌고 있는 드럼이 있을 때만 이어 그림).
- 집 하나(`mokryeon_180b`)만 새 렌더러다. 다른 집은 지금 iframe 뷰어 그대로 트윈 칸에 둔다. 설정 화면 벽 고르기는 iframe 그대로다.
- 배치를 바꾸면 바로 보인다. 다시 굽기 전까지 옛 자리 그림자가 남고 새 물건은 그림자가 없다(받아들임). 다시 굽기는 필요할 때 twin-studio에서 손으로(약 7분).
- 말: 「대시보드 폰 칸」(화면 이름 「폰 카메라」)과 「실제 폰」. 맨 「폰 화면」은 쓰지 않는다(`ui/tests/dashboard/wording.test.ts`).
- 화면 글 크기는 21st.dev 부품 원래 크기다. 더 큰 글은 말풍선 카드 글(Item `say`: 16px 굵게 가운데) 하나뿐이다(`scripts/lint-ui-type.ts` `USER_SIZES` 한 줄).

- [ ] **Step 5: 구현 — 복사** — `scripts/twin-assets.ts`의 `copyTwinAssets`를 아래로 바꾸고 맨 아래 CLI가 `--only`(여러 번)를 받게 한다. 머리 주석의 「복사:」 줄에 `drawn_fixtures.json`·`bake/`·`--only`를 적는다.

```ts
/** 구운 결과 중 화면이 읽는 것. 굽기 장면·중간 파일(bake.blend, lm/, lm<n>.png, layout.json, timings.json)은 twin-studio에 남는다. */
const BAKE_FILE = /^(?:[\w-]+_baked\.glb|lm\d+\.webp|ground\.png|manifest\.json)$/;
const HOME_DATA = ["floorplan.json", "placement.json", "drawn_fixtures.json"];
type Entry = { path: string; bytes: number; sha256: string; commit?: string };
const byPath = (a: Entry, b: Entry) => (a.path < b.path ? -1 : a.path > b.path ? 1 : 0);

export function copyTwinAssets(o: { from: string; to: string; commit?: string; only?: string[] }): { files: number; bytes: number; commit: string } {
  const from = resolve(o.from);
  const to = resolve(o.to);
  checkTarget(to, from);
  const reg = readRegistry(from);
  const commit = o.commit ?? gitCommit(from);
  const only = o.only?.map((p) => p.replace(/\\/g, "/"));
  const wanted = (rel: string) => !only || only.some((p) => (p.endsWith("/") ? rel.startsWith(p) : rel === p));
  const relOf = (p: string) => relative(from, p).replace(/\\/g, "/");
  const picks = new Set<string>([join(from, "homes.json")]);
  walk(reg.viewerDir, (rel) => rel === "test" || rel.startsWith("test/")).forEach((p) => picks.add(p));
  walk(join(reg.libraryDir, "assets")).forEach((p) => picks.add(p));
  walk(join(from, "data", "catalog")).forEach((p) => picks.add(p));
  for (const h of reg.homes) {
    if (existsSync(h.scenePath)) picks.add(h.scenePath);
    else if (!only) throw new Error(`집 ${h.id}의 scene.json이 없어요(${h.scenePath}). twin-studio에서 먼저 빌드하세요.`);
    walk(join(h.outDir, "assets")).forEach((p) => picks.add(p));
    const bake = join(h.outDir, "bake");
    walk(bake).filter((p) => dirname(p) === bake && BAKE_FILE.test(basename(p))).forEach((p) => picks.add(p));
    for (const f of HOME_DATA) if (existsSync(join(h.dataDir, f))) picks.add(join(h.dataDir, f));
    walk(join(h.dataDir, "catalog")).forEach((p) => picks.add(p));
  }
  const chosen = [...picks].filter((p) => wanted(relOf(p))).sort();
  if (only && chosen.length === 0) throw new Error(`--only ${only.join(", ")}에 맞는 파일이 없어요.`);
  let kept: Entry[] = [];
  let top = commit;
  if (only) {
    if (!existsSync(join(to, "SOURCE.json"))) throw new Error(`--only는 이전 복사 결과가 있는 폴더에만 써요(${to}).`);
    const prev = JSON.parse(readFileSync(join(to, "SOURCE.json"), "utf8")) as { commit: string; files: Entry[] };
    top = prev.commit;
    kept = prev.files.filter((f) => !wanted(f.path));
    for (const f of prev.files.filter((x) => wanted(x.path))) rmSync(join(to, f.path), { force: true });
  } else rmSync(to, { recursive: true, force: true });
  const files: Entry[] = [];
  for (const p of chosen) {
    const rel = relOf(p);
    const dest = join(to, rel);
    mkdirSync(dirname(dest), { recursive: true });
    const body = TEXT.test(rel) ? Buffer.from(readFileSync(p, "utf8").replace(/\r\n/g, "\n"), "utf8") : readFileSync(p);
    if (TEXT.test(rel)) writeFileSync(dest, body);
    else copyFileSync(p, dest);
    files.push({ path: rel, bytes: body.length, sha256: createHash("sha256").update(body).digest("hex"), ...(only ? { commit } : {}) });
  }
  const all = [...kept, ...files].sort(byPath);
  writeFileSync(join(to, "SOURCE.json"), `${JSON.stringify({ source: "twin-studio", commit: top, homes: reg.homes.map((h) => h.id), files: all }, null, 2)}\n`);
  return { files: files.length, bytes: files.reduce((a, f) => a + f.bytes, 0), commit };
}
```

```ts
// 구운 3D의 drawn_<id> 노드와 같은 파일에서 와서 자리가 같다. 옮길 수 없고(interactive false) 기기가 아니다(attrs 없음).
import type { SceneJson, SceneObject } from "../layout/editor.js";

export interface DrawnFixture {
  id: string; kind: string; room: string; position: [number, number]; facing_deg: number; footprint: [number, number]; height: number;
  /** 개수대 가운데(싱크 조리대만). */
  sink?: [number, number];
}

export const DRAWN_NAME: Record<string, string> = { sink_counter: "싱크대", counter: "조리대", toilet: "변기", vanity: "세면대", bathtub: "욕조" };

const round = (v: number) => Math.round(v * 1e6) / 1e6;

export function drawnObject(f: DrawnFixture, roomLabel: string | undefined): SceneObject {
  const [x, y] = f.position;
  const kind = DRAWN_NAME[f.kind] ?? f.kind;
  return {
    id: f.id, name: roomLabel ? `${roomLabel} ${kind}` : kind, type: f.kind, asset: null, category: "fixtures", mount: "floor", room: f.room,
    plan: { position: [x, y], facing_deg: f.facing_deg, elevation: 0, on: null, surface: null, wall: null },
    position: [x, 0, y], rotation: [0, round(((90 - f.facing_deg) * Math.PI) / 180), 0], scale: [1, 1, 1],
    interactive: false, attrs: {}, states: {}, state: {}, footprint: f.footprint, height: f.height,
    ...(f.sink ? { anchors: { basin: f.sink } } : {}),
    provenance: { origin: "plan_drawing", size: "plan", facing: "plan", height: "plan", model: "drawn", builder: "drawn" },
  };
}

/** scene.json 물건 뒤에 도면 설비를 더한다. 같은 id가 이미 있으면 더하지 않는다. */
export function withDrawn(scene: SceneJson, fixtures: DrawnFixture[]): SceneJson {
  const have = new Set(scene.objects.map((o) => (o as { id?: string }).id));
  const label = new Map((scene.plan.rooms ?? []).map((r) => [r.id, r.label]));
  const add = fixtures.filter((f) => !have.has(f.id)).map((f) => drawnObject(f, label.get(f.room)));
  return add.length ? { ...scene, objects: [...scene.objects, ...add] } : scene;
}
```

```ts
import * as THREE from "three";
import { basis, type OrthoCamera } from "./projection";

export interface MapCamera { cx: number; cy: number; scale: number }
export interface Box { width: number; height: number }
export const CAMERA_MS = 380;
/** Blender 좌표 → three(x, 높이, −y). */
const b2t = ([x, y, z]: [number, number, number]) => new THREE.Vector3(x, z, -y);

/** 지도 카메라가 보는 그림 네모를 카메라 면(m) 틀로. 그림 1px = orthoScale / width m, shift는 orthoScale 몫. */
export function frustumOf(v: OrthoCamera, c: MapCamera, box: Box) {
  const m = v.orthoScale / v.width;
  const hw = box.width / (2 * c.scale);
  const hh = box.height / (2 * c.scale);
  const a = (u: number) => (u - v.width / 2) * m + v.shiftX * v.orthoScale;
  const b = (y: number) => (v.height / 2 - y) * m + v.shiftY * v.orthoScale;
  return { left: a(c.cx - hw), right: a(c.cx + hw), top: b(c.cy - hh), bottom: b(c.cy + hh) };
}

export function placeCamera(cam: THREE.OrthographicCamera, v: OrthoCamera, c: MapCamera, box: Box): void {
  Object.assign(cam, frustumOf(v, c, box), { near: 1, far: 200 });
  const target = b2t(v.target);
  cam.position.copy(target).add(b2t(basis(v).toward).multiplyScalar(60));
  cam.up.set(0, 1, 0);
  cam.lookAt(target);
  cam.updateProjectionMatrix();
  cam.updateMatrixWorld();
}

export function projectThree(cam: THREE.Camera, box: Box, [x, h, z]: [number, number, number]) {
  const p = new THREE.Vector3(x, h, z).project(cam);
  return { x: ((p.x + 1) / 2) * box.width, y: ((1 - p.y) / 2) * box.height };
}

export const screenOf = (c: MapCamera, box: Box, [u, v]: [number, number]) => ({ x: box.width / 2 + (u - c.cx) * c.scale, y: box.height / 2 + (v - c.cy) * c.scale });
export const plateTransform = (c: MapCamera, box: Box) => `translate(${box.width / 2 - c.cx * c.scale}px, ${box.height / 2 - c.cy * c.scale}px) scale(${c.scale})`;

export function between(a: MapCamera, b: MapCamera, box: Box, t: number): MapCamera {
  if (t <= 0) return a;
  const T = (c: MapCamera) => [box.width / 2 - c.cx * c.scale, box.height / 2 - c.cy * c.scale] as const;
  const [ax, ay] = T(a); const [bx, by] = T(b);
  const s = a.scale + (b.scale - a.scale) * t;
  const x = ax + (bx - ax) * t; const y = ay + (by - ay) * t;
  return { scale: s, cx: (box.width / 2 - x) / s, cy: (box.height / 2 - y) / s };
}

/** cubic-bezier(0.22, 1, 0.36, 1)(대시보드 motion EASE와 같은 곡선). */
export function ease(t: number): number {
  if (t <= 0) return 0;
  if (t >= 1) return 1;
  const [x1, y1, x2, y2] = [0.22, 1, 0.36, 1];
  const f = (u: number, p1: number, p2: number) => 3 * (1 - u) ** 2 * u * p1 + 3 * (1 - u) * u * u * p2 + u ** 3;
  let lo = 0, hi = 1, u = t;
  for (let i = 0; i < 30; i++) { u = (lo + hi) / 2; if (f(u, x1, x2) < t) lo = u; else hi = u; }
  return f(u, y1, y2);
}
```

```ts
// 승인 질문은 대시보드에 보이지 않는다(D37): 단계 id가 :approve로 끝나는 명령은 없는 것으로 본다.
import type { PlannedCommandMessage } from "../contract/phone.js";
import type { PlanView } from "../contract/plan.js";
import type { WorldView } from "../contract/world.js";
import { SAY_TEXT } from "../plan/labels.js";
import { cupStepOf, planTargetId } from "./tasks.js";

export const SAY_DONE_MS = 20_000;
const OPEN = new Set<PlanView["status"]>(["planned", "running"]);

export function sayLine({ plan, command, world, nowMs }: { plan: PlanView | null; command: PlannedCommandMessage | null; world: WorldView | null; nowMs: number }): string {
  if (plan && OPEN.has(plan.status)) {
    const sent = command?.type === "command" && command.id === plan.id && !command.step.endsWith(":approve") ? command : null;
    if (sent && sent.choices.length > 1) return SAY_TEXT.asked;
    const step = sent ? plan.steps.find((s) => s.id === sent.step) : undefined;
    const key = step ? cupStepOf(step) : null;
    if (key) return SAY_TEXT.told[key];
    const cupId = planTargetId(plan);
    const surface = cupId ? world?.objects.find((o) => o.id === cupId)?.surface_label ?? null : null;
    return SAY_TEXT.decided(plan.goal, surface);
  }
  if (plan && nowMs - Date.parse(plan.updatedAt) <= SAY_DONE_MS) return plan.status === "done" ? SAY_TEXT.done(plan.goal) : SAY_TEXT.stopped(plan.goal);
  const seen = world?.objects.filter((o) => o.status !== "gone" && o.surface_label).sort((a, b) => b.last_seen_ms - a.last_seen_ms)[0];
  return seen?.surface_label ? SAY_TEXT.looking(seen.surface_label) : SAY_TEXT.watching;
}
```
