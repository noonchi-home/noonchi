# 메시지 상자 FSM 카드 · 트윈 번호 길 Implementation Plan

> **쉬운 요약**
> 1. 메시지 상자에서 알약 셋(상태·트리거·액션)과 목표 알약을 뺀다. 상자 높이는 마스코트 눈 높이쯤(128 → 170px)이다. 왼쪽은 지금처럼 세 줄이 굴러간다.
> 2. 상자 오른쪽에 둥근 카드(21st.dev Card) 하나: 습관 FSM 상태 그림(원 = 상태, 위 이름 · 아래 하는 일, 화살표 = 트리거, 제자리 고리). 지금 상태는 LG 빨강. 카드는 지금 상태를 가운데에 두고, 상태가 바뀌면 빨간 점이 화살표를 따라가고 카드가 새 상태로 옮겨 간다. 앞 상태는 흐려진다.
> 3. 목표는 카드에 그리지 않는다. 사람 FSM과 따로 된 상태 머신(세움 → 준비됨 → 시작 → 끝/버림)이라 한 줄 「목표 · 컵 치우기 · 준비됨」으로 보인다(자리는 배치를 정할 때까지 메시지 상자 문장 칸 위).
> 4. 트윈 왼쪽 위 할 일 진행도 알약을 뺀다. 로봇 상태 알약은 두지 않는다(메시지 상자 최신 줄이 로봇이 하는 일을 말한다).
> 5. 트윈 위에 계획 길: 로봇에서 단계 자리까지 선, 번호 ①②③④(지금 단계 빨강, 끝난 단계 흐림), 지금 단계 이름표, 사람 이름표(「사람 · 마시는 중」). 목표 이름표는 트윈에 없다.
> 6. 「무엇을 어디에 그릴지」(월드 좌표·글)와 「그리기」(트윈 판)를 나눠, 나중에 폰 카메라 화면 위에도 같은 표시를 그릴 수 있게 한다.

**Goal:** 대시보드 메시지 상자에 습관 FSM 상태 그림 카드를 넣고, 트윈 위 계획을 번호 길로 보인다.

**Architecture:** 서버는 판단이 PAM에 보낸 기억(판본)이 바뀔 때 화면 글이 붙은 습관 FSM 그림 자료(`HabitFsm`, `src/brain/habit.ts` `habitView`)를 `{type:"habit"}`로 보내고 접속 때 다시 보낸다. 지금 상태는 판단 기록의 `fsm.state`(`fsmNow`) 그대로, 목표는 `{type:"goal"}` 그대로다. 화면은 순수 함수 `fsmViewOf`(`ui/src/dashboard/fsm.ts`)가 상태 줄 세우기·선·글 자리를 정하고 `FsmCard`가 21st.dev 부품(Card 틀, Avatar 원, Separator 줄, Line Draw SVG 선, Status 글)을 놓는다. 트윈 계획 길은 순수 함수 `planMarks`(`ui/src/dashboard/plan-marks.ts`, 월드 좌표 `[x, 높이, z]`와 글)와 트윈 판 그리기(`MapOverlay`)로 나눈다.

**Tech Stack:** TypeScript, React 19, Vitest(jsdom), 21st.dev 부품(`ui/src/components/ui`), 디자인 토큰(`src/design/tokens.json` → `npm run tokens`).

**Spec:** 사용자가 고른 구조 스케치(`fsm-panel.html`·`box-fsm-b2.html`, 참고 그림 `fsm_example.jpg`)와 조정자 전달 결정(2026-11-18).

## Global Constraints

- 화면 부품은 21st.dev 부품을 그대로 쓰거나 받은 코드를 고친 것만(출처 줄 · `// 바꾼 것:` 줄). 화면 코드는 배치만(꾸밈 class·style 없음). `npm run lint`.
- 색은 디자인 토큰만, 글 크기는 부품 원래 크기, 화면 글은 할 일과 지금 상태만(화살표 `→` 금지).
- 단계가 바뀔 때 움직임은 transform·opacity만(`element.animate`), 움직임 줄이기면 움직이지 않는다. 트윈 캔버스·영상·칸 크기는 그대로.
- TDD: 새 시험이 먼저 실패하는 것을 본다. 무거운 일은 `npm run heavy -- <cmd>`(3이면 다시).
- 계약을 바꾸면 ui 빌드와 ui 시험도 돌린다.

## Task 1: 서버 습관 FSM 그림 자료

**Files:** Create `src/brain/habit.ts`, `tests/brain-habit.test.ts`. Modify `src/contract/pam.ts`(`HabitFsm`), `src/contract/events.ts`(`{type:"habit"}`), `src/world/labels.ts`(`NEXT_ON`), `src/brain/index.ts`, `src/server/home/act.ts`(`publishHabit`), `src/server/home/core.ts`(`habit`), `src/server/home/index.ts`·`src/server/app.ts`(`habitLast`), `ui/src/lib/messages.ts`, `tests/server.test.ts`, `tests/habit-server.test.ts`.

**Interfaces (Produces):**
- `interface HabitFsm { version: number; initial: string; states: { id: string; name: string; learned: boolean }[]; transitions: { from: string; to: string; trigger: string; action: string | null; learned: boolean }[] }` — 상태 목록 + 전이 목록(사람 상태 FSM도 같은 모양).
- `habitView(memory: FsmMemory, version: number): HabitFsm` — 이름은 `FSM_STATE_TEXT`(없으면 설명 첫 마디), 규칙은 조건 `ruleIf`와 행동이 있는 제자리 전이, 상태 넘김은 `NEXT_ON` 글(없으면 끝 마침표 뗌)의 행동 없는 전이, learned는 seed(`CUP_FSM_MEMORY`)에 없는 것.
- `publishHabit(core, h)`: 판본이 바뀔 때만 `{type:"habit"}` 방송, 마지막 것을 `core.habit`에 둔다. 판단 기록(`emit` decision)에서 `decider.habit()`으로 부른다. 접속 때 `habitLast`.
