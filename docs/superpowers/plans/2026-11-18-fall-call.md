# 쓰러짐 뒤 보호자 전화 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**쉬운 요약:**
1. 코치 모드에서 쓰러짐 의심이 뜨면 폰이 「괜찮으세요?」라고 묻고 8초 듣고, 한 번 더 묻고 8초 듣는다.
2. 「괜찮아」면 멈추고, 「도와줘」면 바로, 대답이 없으면 감지 뒤 약 21초에 보호자에게 전화한다. 폰 승인 없이 거는 전화는 이 길 하나뿐이다.
3. 전화는 Twilio(전화 거는 클라우드 서비스)로 걸고 OpenAI 실시간 음성 모델이 보호자와 바로 말한다. 쓰러진 뒤 보호자가 첫마디를 듣기까지 약 38초(받는 데 10초로 셈), 보호자 질문에 약 1초 만에 답한다.
4. 보호자에게는 누가·어느 방·몇 시·대답 없음·지금 자세만 말하고 사진은 보내지 않는다. 대시보드는 지금 상태 한 줄만 보인다.
5. 빌드는 가로 영상 시험이 끝난 뒤 한다. 맨 끝에 사용자만 답할 질문 9개가 있다.

**Goal:** 코치 모드에서 서 있던 사람이 쓰러지면 폰이 말로 묻고, 대답이 없으면 등록한 보호자에게 전화해 에이전트가 보호자와 직접 말한다.

**Architecture:**
- 실행 추적에 새 부분 `FallCheck`(`src/act/track/fall.ts`)를 둔다. World State 사람 자세가 `fall_suspected`가 되면 폰 명령 줄을 가장 먼저 차지해 묻고 듣고, 결과를 사건(`FallEvent`)으로 낸다.
- `FallCall`(`src/act/fall-call.ts`)이 사건을 받아 대시보드 한 줄·기록 DB `emergency` 줄을 남기고 보호자에게 전화한다. 받는 이는 `contacts.json`에서만 온다.
- 전화 길은 외부 API 통로 `src/infer/voice-call/`(Twilio 전화 + OpenAI 실시간 음성)다. 공개 주소로는 전화 전용 포트(`CALL_PORT`)의 두 경로만 연다.
- 말로 시킨 `call_service`(승인을 묻는 AS센터·보호자 연락)와 `CALL_SERVICE_URL`은 바꾸지 않는다.

**Tech Stack:** Node 22 TypeScript, `ws`, Vitest, Twilio Programmable Voice(Calls REST, `<Connect><Stream>` 양방향 소리, 상태 알림), OpenAI Realtime(`gpt-realtime-1.5`, G.711 μ-law 그대로), 크롬 내장 음성 인식(실제 폰), 영상 판정 `scripts/video-check.ts`.

**Spec:** 사용자 요청(2026-11-18): 「코치 모드에서 서 있던 사람이 갑자기 쓰러지면(쓰러짐 자세 감지) 로봇이 말로 『괜찮으세요?』라고 묻고, 몇 초 동안 반응이 없으면 보호자에게 전화하고, 그 통화에서 AI 에이전트가 보호자와 직접 말한다.」 2026-11-16 회의록 「안전 계층은 낙상·의식불명에 집중」, 「서 있다가 짧은 시간에 누움 → 낙상 의심 → 괜찮으신가요? → 답이 있으면 원래대로, 일정 시간 답이 없으면 긴급 연락」, 「시연은 팀원 폰을 보호자로 쓰고 119는 실제로 걸지 않는다」. 사용자 결정: 쓰러짐 감지는 YOLO 관절 그대로. 사용자 우선순위: 속도.

## 조사한 사실 (6d6e4cf, `refactor/domain-split`, 2026-11-18)

- **쓰러짐 감지**(`src/world/fall.ts`, `src/world/state/people.ts`): 서 있음에서 2초(`FALL_DROP_MS`) 안에 중력 기준으로 몸통·허벅지가 다 누운 자세가 되고 3초(`FALL_HOLD_MS`) 이어지면 사람 자세 사실을 `fall_suspected`로 두고 의미 있는 변화 줄 「사람 쓰러짐 의심」을 한 번 낸다. 서 있음·앉아 있음이 보이면 풀린다. 카메라 자세가 없으면(맞추기 전) 보류한다. 침대·소파는 VLM `on_bed`·`on_sofa` 근거가 있을 때만 뺀다.
- 대시보드 말풍선 카드(`src/act/say.ts` `sayLine`)는 자세가 쓰러짐 의심이면 무엇보다 먼저 「사람이 쓰러진 것 같아요.」다. PAM 관찰 텍스트에도 들어가지만 PAM 행동 목록(`src/act/tasks.ts`)에 연락 행동은 없다. 지금은 아무도 묻지도 연락하지도 않는다.
- **`call_service`**(`src/agent/tools.ts`·`service.ts`·`policy.ts`): 서버 안 말 요청 에이전트에만 있고 말로 시킨 요청에서만 불린다. 늘 실제 폰으로 승인을 먼저 묻는다(`askService`, 기억 안 함). 받는 이는 `runtime/homes/<집>/contacts.json`(`as_center`·`guardian`, 이름 40자·번호)뿐이다.
- **`CALL_SERVICE_URL`의 계약**(`src/infer/call-service.ts`, `docs/reference.md` 「외부 연락」): 승인한 연락 하나를 JSON(판본 1: id·kind·to·home·device·problem·error_code·person·approved_at)으로 한 번 POST한다. 10초 제한, 답 본문은 읽지 않는다, 2xx면 「보냄」. 전화 서비스는 같은 id를 한 번만 처리해야 한다. **양방향 통화를 실을 자리가 없다**(한 번 보내고 끝, 대화·상태 알림·소리 통로 없음).
- **실제로 전화를 거는 것은 없다.** 이 저장소·docs 저장소 어디에도 그 주소를 받아 전화를 거는 서비스가 없다. compose의 `CALL_SERVICE_URL`은 비어 있고, 시험은 가짜 HTTP 서버(`tests/helpers/call-service.ts`)만 쓴다. 11-16 회의에서 신지훈이 전화 발신 서비스 조사(11-17까지)를 맡았고 결과 문서는 아직 없다.
- **코치 모드**는 「돕는 방식」 `AssistMode = "coach"`(`src/contract/setup.ts`, `runtime/setup.json` `assist`, `POST /api/setup/assist`, 설정 화면)다. PAM에는 코치 행동과 「사용자에게 물어보기」만 보낸다(`tasksFor`). 코치 계획이 열려 있거나 만드는 중이면 PAM을 쉰다(`ExecutionTracker.coaching()`). 운영 모드(test·live)와 상관없다.
- **폰 소리**(`ui/src/phone/core/talk.js`): 크롬 음성 인식(ko-KR)을 늘 켜 두고 끝난 말만 보낸다. 폰이 읽는 동안은 듣기를 멈추고, 끝나면 0.3초 뒤 다시 켠다. 읽기는 1.05배. 들은 말은 폰 서버 `onAnswer`(실행 추적 `onHeard`가 먼저) → 아니면 `onSay`(말 요청 에이전트)로 간다(`src/server/home/phone.ts`).
- 새 폰 질문은 지금 명령 줄로 보내고 답 말을 `QUESTION_CHOICES`에 둬야 한다(`tests/voice-answers.test.ts`). 말 맞추기 `matchChoice`(`src/act/tasks.ts`)는 `whole`이면 말 전체(앞 응·네·이제, 끝 요·해 허용), 아니면 말 안 어디든이다.
- 소리 등급(`src/act/talk-grade.ts`): `safety`·`question`은 끝까지 읽고 먼저 읽는다. 명령이 `safety`면 서버가 승인 대기 시간 제한을 멈춘다(`src/server/home/act.ts` `policy.pause`).
- 기록 DB 종류(`src/contract/history.ts`, `src/brain/history/db.ts` `HISTORY_KINDS`)에 응급 줄이 없다. `service` 줄은 `KEEP_HEARD_TEXT`가 꺼져 있으면 받는 이·내용을 가린다.
- 영상 모드(폰 `?clip=`)는 마이크 듣기만 끄고 읽기·명령·판단은 같다. 영상 판정 `scripts/video-check.ts`의 `--say <초>:<글>`이 폰 소켓으로 말을 넣는다. `--assist` 칸은 아직 없다. 영상이 끝나면 끝 장면을 붙잡아 계속 보낸다.
- 루트 시험은 실제 AI 주소 fetch를 막는다(`tests/setup/no-real-ai.ts`). 전화 주소 차단은 없다.
- 서버·폰 포트는 compose에서 `127.0.0.1`만 열고, 폰은 tailscale serve(내 tailnet 안)로만 닿는다. **밖(Twilio)에서 닿는 공개 주소가 없다.**

OpenAI `gpt-realtime-1.5` 소리 토큰 100만 개당 듣기 $32·말하기 $64·캐시 $0.40(https://developers.openai.com/api/docs/models/gpt-realtime-1.5), 소리 토큰은 듣기 0.1초·말하기 0.05초마다 1개라 분당 듣기 약 $0.019·말하기 약 $0.077.

## 정한 것

### 1. 순서와 시간

| 차례 | 하는 일 | 시간 |
|---|---|---|
| 0 | World State가 사람 자세를 `fall_suspected`로 둠(바닥에 닿은 뒤 약 3초) | 감지 규칙 그대로 |
| 1 | 코치 모드면 폰 명령 줄에 「괜찮으세요?」(안전 등급, 답 「도와주세요」·「괜찮아요」). 열린 계획은 멈춘다 | 읽기 약 1.1초 |
| 2 | 다 읽은 뒤 8초 듣는다 | 8초 |
| 3 | 대답 없으면 「괜찮으세요? 대답이 없으면 보호자에게 전화할게요.」 | 읽기 약 3.5초 |
| 4 | 다 읽은 뒤 8초 듣는다 | 8초 |
| 5 | 대답 없으면 보호자에게 전화. 폰은 「보호자에게 전화하고 있어요.」 | 감지 뒤 약 21초 |
| 6 | 보호자가 받으면 에이전트가 첫마디로 사실을 말하고 묻는 것에 답한다. 폰은 「보호자와 통화하고 있어요.」 | 받은 뒤 약 0.5초 |
| 7 | 통화가 끝나면 폰 「보호자에게 알렸어요.」 | |

- **듣는 시간 8초**(`FALL_LISTEN_MS`, 질문을 다 읽은 뒤부터): 다시 켜기 0.5초 + 쓰러진 뒤 멍한 사람이 말을 시작하기까지 2~4초 + 말 1초 + 크롬이 끝난 말을 내기까지 1~1.5초 = 4.5~7초에 1초 넘게 남긴다. 더 줄이면 느린 대답을 놓쳐 잘못 거는 전화가 는다.
- **다 읽은 때**는 서버가 어림한다: `speakMs(글) = 300 + 140 × 공백 뺀 글자 수`(ms, 1.05배 한국어 읽기 초당 약 7글자). 폰에 새 알림 메시지를 만들지 않는다.
- **묻기 2번**(`FALL_ASKS`, 1~3): 한 번만 들으면 TV 소리·잠깐 멍함에도 바로 건다. 두 번째 질문이 「전화할게요」를 알려 잘못 감지했을 때 사람이 멈출 수 있다. 1번이면 감지 뒤 약 9초에 건다(질문 7번).

### 2. 대답으로 보는 것

| 들은 말 | 보는 법 | 하는 일 |
|---|---|---|
| 도움 말: 도와·살려·아파요·아야·119·구급차·전화해·못 일어나·안 괜찮 | 말 안 어디에 있어도 | 남은 질문 없이 바로 전화 |
| 괜찮음 말: 괜찮아·괜찮습니다·괜찮다·멀쩡해·안 다쳤어·전화하지 마·그만 | 말 전체일 때만(앞 응·네, 끝 요·해 허용) | 멈춤. 폰 「다행이에요」 |
| 그 밖의 말(「아이고」, 주변 말 포함) | 질문에 온 말이면 | 알아듣지 못함: 바로 다음 질문을 「괜찮으시면 괜찮아라고, 도움이 필요하면 도와줘라고 말해 주세요.」로. 마지막 질문 뒤면 기다림을 이어 가고 끝나면 전화 |
| 신음·말소리 없음 | 인식 글이 없음 | 대답 없음 |
| 단추 「도와주세요」·「괜찮아요」 | 말과 같음 | 보조 |

- 도움 말은 놓치지 않게 넓게(어디든), 괜찮음 말은 TV 소리에 멈추지 않게 좁게(말 전체) 본다. 「아파」는 「아파트」에 걸려 「아파요」만 쓴다. 「불러」는 「노래 불러」에 걸려 뺀다.
- 말할 때 폰에 떠 있던 명령(`at`)이 이 쓰러짐 질문이 아니면 버린다(늦은 답 규칙 그대로).
- 일어나도(서 있음·앉아 있음) 멈추지 않는다. 관절이 한 장 잘못 봐도 풀리기 때문이다. 일어난 것은 전화의 「지금」 사실로 넘긴다.
- 「괜찮아」 뒤 2분(`FALL_RECHECK_MS`) 넘게 계속 쓰러짐 의심이면 한 번 더 같은 차례로 묻는다. 일어났다가 다시 쓰러지면 새로 묻는다.

### 3. 승인 없는 전화: 이 길만, 좁게

- 의식이 없을 수 있는 사람에게 「승인」을 받을 수 없다. 대신 **두 번 묻고 대답이 없는 것**을 승인 자리로 본다.
- 좁히는 것:
  - 구조: 전화 통로(`VoiceCaller`)는 서버가 만들어 `FallCall` 하나에만 넘긴다. 에이전트·MCP·PAM 행동에는 넘기지 않는다. `tests/fall-call-narrow.test.ts`가 `VoiceCaller`·`dial(` 쓰는 자리를 본다(Task 7).
  - 조건: 코치 모드 + World State 자세 `fall_suspected` + 질문 차례 끝(대답 없음·도움 말·알아듣지 못함). 받는 이는 `contacts.json`의 `guardian` 하나(번호 있어야 함). 보낼 내용은 서버가 정한 사실뿐(모델이 쓴 글 없음).
  - 한 번 쓰러짐(일어나기 전)에는 전화 한 통(받지 않으면 다시 걸기 2번까지). 통화 중 다시 쓰러짐은 새 전화가 아니라 그 통화의 새 사실이다.
  - 말로 시킨 `call_service`는 지금처럼 늘 승인을 묻는다.
- 잘못 감지했을 때:
  - 멈추는 말(괜찮음 말·「그만」·단추)이 있다.
  - 두 번째 질문이 「대답이 없으면 보호자에게 전화할게요」라고 미리 알린다.
  - 대시보드 카드가 「쓰러진 사람에게 괜찮은지 묻고 있어요.」를 보인다.
  - 걸기 시작한 뒤에는 끊지 않는다. 받지 않은 전화만 남으면 보호자가 더 걱정한다. 대신 그 뒤 들은 대답·일어남을 통화에서 바로 알린다(「방금 괜찮다고 대답하셨어요.」).

### 4. 전화 거는 법

**지금 `CALL_SERVICE_URL`로는 안 된다.** JSON 한 번 보내고 끝이라 소리·대화·받음 알림을 실을 수 없고, 그 주소를 받아 거는 서비스도 없다. 그래서 이 저장소 안에 전화 통로를 새로 만든다(저장소 규칙: 아키텍처에 쓰는 코드는 이 저장소에).

| | A 실시간 음성(추천) | B 읽기 + 듣기 | C 안내만 |
|---|---|---|---|
| 방법 | Twilio가 걸고, 받으면 소리를 우리 서버로 잇고(`<Connect><Stream>`), 서버가 OpenAI 실시간 음성 모델과 소리를 그대로 주고받는다 | Twilio가 걸어 사실을 읽고(`<Say>`), 보호자 말을 글로 받아(`<Gather>`) 서버 LLM이 쓴 답을 다시 읽는다 | Twilio가 걸어 사실 안내를 두 번 읽고 끊는다 |
| 쓰러짐 → 감지 | 3초 | 3초 | 3초 |
| 묻기 2번·듣기 | 21초 | 21초 | 21초 |

- **추천 A.** 첫마디까지는 셋이 같지만 대화는 A가 3~5배 빠르다. 다급한 보호자가 묻는 「어디예요?」에 1초 안에 답한다. 값은 B와 같다. 저장소가 이미 OpenAI와 `ws`를 쓴다.
- A의 받기 전 준비: 걸기 요청이 접수되면 바로 실시간 모델을 열고 첫마디 소리를 만들어 둔다. 받는 즉시 보낸다.
- A가 망가질 때: TwiML을 `<Connect><Stream/></Connect><Say>사실 안내</Say>`로 둔다. 실시간 연결이 안 되면 서버가 스트림을 닫고 Twilio가 C처럼 안내를 읽는다.
- 공개 주소: 전화 전용 포트 `CALL_PORT`(8220, `127.0.0.1`)를 따로 열고 두 경로만 둔다: `POST /call/status/<토큰>`(상태 알림, Twilio 서명 검사), `WS /call/stream/<토큰>`(소리). 토큰은 전화마다 새 48자, 그 전화가 살아 있는 동안 한 번만 받는다. 밖에서는 Tailscale Funnel로 이 포트만 연다(`tailscale funnel --https=8443 http://127.0.0.1:8220`). 대시보드·폰 포트는 그대로 닫혀 있다.
- 발신 번호: 미국 Twilio 번호면 보호자 폰에 국제전화(+1)로 뜬다. 한국 번호는 사업자 서류가 필요하다(질문 3).
- 받지 않음·통화 중·실패: 20초(`CALL_RETRY_GAP_MS`) 뒤 다시 건다, 2번까지(`CALL_RETRIES`). 울림은 30초(`CALL_RING_S`). 음성사서함이 받아도 첫마디에 사실이 다 들어 있어 남는다(받음으로 센다).
- 통화는 3분(`CALL_MAX_MS`)이 되면 마무리 인사를 하게 하고 15초 뒤 끊는다.

### 5. 통화에서 하는 말

- **사실**(`CallFacts`, 서버가 만든다): 누가(`contacts.json`의 새 칸 `resident.name`, 없으면 「집에 계신 분」), 어느 방(World State 사람 방, 모르면 「집 안」), 몇 시(쓰러짐 의심 시각, 기록 시간대 「오후 3시 12분」), 확인 결과(대답 없음·도와 달라고 함·알아듣지 못함), 지금 자세(누워 있음·일어남·안 보임), 하던 일(열린 계획 이름, 「라면 끓이기」), 켜진 위험 가전 이름(인덕션 등).
- **첫마디**(고정 글): 「안녕하세요. 눈치 홈로봇의 AI예요. 어머니께서 오후 3시 12분쯤 주방에서 쓰러지신 것 같아요. 두 번 괜찮으시냐고 여쭸는데 대답이 없으셨어요. 지금도 누워 계세요. 궁금한 것을 물어보세요.」 AI라고 먼저 밝힌다.
- **답해도 되는 것**: 위 사실, 그 뒤 바뀐 것(새 사실 메시지), 할 수 없는 일 안내, 「119에 직접 신고해 주세요」.

- **통화 중 새 사실**: 폰이 들은 대답(괜찮음·도움·알아듣지 못함)과 자세(일어남·다시 누움)를 「[새 사실] 방금 괜찮다고 대답하셨어요.」처럼 넣고 바로 한 문장으로 말하게 한다. 사람이 한 말 글은 넘기지 않는다.
- **개인정보**: 사진·영상은 보내지 않는다. 보호자 소리는 Twilio를 거쳐 OpenAI로 가고, 쓰러진 사람의 말은 어디에도 보내지 않는다. 받아쓰기(전사)는 `KEEP_HEARD_TEXT=1`일 때만 켠다. 기록에는 번호·대화 글을 남기지 않는다(같은 설정일 때만 남김).

```ts
const int = (env: Env, key: string, d: number, min: number, max: number) => {
  const raw = env[key]?.trim();
  if (!raw) return d;
  const v = Number(raw);
  if (!Number.isInteger(v) || v < min || v > max) throw new Error(`${key}=${raw}: ${min}~${max} 정수여야 합니다`);
  return v;
};
```

```ts
// 한 번 쓰러짐(일어나기 전)에는 한 회차다. 괜찮음 뒤 recheckMs 넘게 계속 쓰러짐 의심이면 다시 묻는다.
import type { CallCheck } from "../../contract/call.js";
import type { HeardAt, PlannedCommand } from "../../contract/phone.js";
import { POSE_FALL } from "../../world/vocab.js";
import { FALL_CALL_DEFAULTS, speakMs, type FallCallConfig } from "../fall-call.js";
import { fallId } from "../fall-step.js";
import { EXEC_TEXT, FALL_TEXT } from "../labels.js";
import { FALL_CHOICES } from "../prompts.js";
import { matchChoice } from "../tasks.js";
import type { HeardResult } from "./answers.js";
import { OPEN, Part, type Run } from "./core.js";

export type FallEvent =
  | { kind: "asked"; episode: string; n: number; fellAt: number; at: number }
  | { kind: "heard"; episode: string; answer: "ok" | "help" | "other"; via: "voice" | "button"; text: string; at: number }
  | { kind: "ok"; episode: string; at: number }
  | { kind: "call"; episode: string; reason: CallCheck; fellAt: number; doing: string | null; at: number }
  | { kind: "posture"; episode: string; now: "up" | "lying"; at: number };

interface Episode {
  id: string; fellAt: number; asked: number; listenUntil: number; heard: "none" | "unclear";
  phase: "asking" | "calling" | "talking"; sent: PlannedCommand | null; paused: { run: Run; at: number } | null; up: boolean;
}

/** 하던 일 이름: 코치 행동 이름의 「알려 주기」를 뗀다(「라면 끓이기 알려 주기」 → 「라면 끓이기」). */
const doingOf = (task: string) => task.replace(/\s*알려 주기$/, "");
const CHOICES = FALL_CHOICES.map(({ id, label }) => ({ id, label }));

export class FallCheck extends Part {
  #ep: Episode | null = null;
  #n = 0;
  #armed = true;
  #okAt: number | null = null;

  private get fcfg(): FallCallConfig { return this.o.fallConfig ?? FALL_CALL_DEFAULTS; }
  private emit(e: FallEvent): void { this.o.onFall?.(e); }

  active(): boolean { return this.#ep !== null; }
  shown(): PlannedCommand | null { return this.#ep?.sent ?? null; }

  /** World State를 본다: 새 회차 시작, 회차 중 자세 바뀜(일어남·다시 누움). */
  see(now: number): void {
    const fact = this.o.world().person.facts.posture;
    const fallen = fact?.value === POSE_FALL;
    const ep = this.#ep;
    if (ep) {
      if (ep.up === fallen) {
        ep.up = !fallen;
        this.emit({ kind: "posture", episode: ep.id, now: fallen ? "lying" : "up", at: now });
      }
      return;
    }
    if (!fallen) { this.#armed = true; this.#okAt = null; return; }
    const recheck = this.#okAt !== null && now - this.#okAt >= this.fcfg.recheckMs;
    if ((this.#armed || recheck) && (this.o.fallCheck?.() ?? false)) this.start(fact!.since_ms, now);
  }

  tick(now: number): void {
    this.see(now);
    const ep = this.#ep;
    if (!ep || ep.phase !== "asking" || now < ep.listenUntil) return;
    if (ep.asked < this.fcfg.asks) return this.ask(now);
    this.call(ep.heard === "unclear" ? "unclear" : "no_answer", now);
  }

  heard(text: string, at: HeardAt | undefined): HeardResult {
    const ep = this.#ep!;
    const choice = matchChoice(text, FALL_CHOICES);
    if (at?.kind !== "command" || at.id !== ep.id) return choice ? { kind: "stale" } : null;
    return this.take((choice?.id ?? "other") as "ok" | "help" | "other", "voice", text);
  }

  answer(planId: string, stepId: string, choice: string): boolean {
    const ep = this.#ep;
    if (!ep || planId !== ep.id || stepId !== ep.sent?.step || !FALL_CHOICES.some((c) => c.id === choice)) return false;
    this.take(choice as "ok" | "help", "button", "");
    return true;
  }

  /** 보호자 전화가 받음(talking)·끝남(ended)이 됐다(src/act/fall-call.ts). */
  phase(episode: string, phase: "talking" | "ended"): void {
    const ep = this.#ep;
    if (!ep || ep.id !== episode) return;
    if (phase === "talking") {
      ep.phase = "talking";
      return this.show(`${ep.id}:talk`, FALL_TEXT.talking);
    }
    this.#ep = null;
    this.core.answers.send({ type: "command_clear", id: ep.id });
  }

  private take(answer: "ok" | "help" | "other", via: "voice" | "button", text: string): HeardResult {
    const ep = this.#ep!;
    const now = this.clock.now();
    this.emit({ kind: "heard", episode: ep.id, answer, via, text, at: now });
    if (ep.phase !== "asking") return { kind: "fall", reply: answer === "other" ? "" : FALL_TEXT.told };
    if (answer === "ok") { this.ok(now); return { kind: "fall", reply: "다행이에요" }; }
    if (answer === "help") { this.call("help", now); return { kind: "fall", reply: "" }; }
    ep.heard = "unclear";
    if (ep.asked < this.fcfg.asks) this.ask(now);
    return { kind: "fall", reply: "" };
  }

  private start(fellAt: number, now: number): void {
    const r = this.core.open();
    this.#armed = false;
    this.#okAt = null;
    this.#ep = { id: fallId(++this.#n), fellAt, asked: 0, listenUntil: 0, heard: "none", phase: "asking", sent: null, paused: r ? { run: r, at: now } : null, up: false };
    this.ask(now);
  }

  private ask(now: number): void {
    const ep = this.#ep!;
    ep.asked++;
    const text = ep.heard === "unclear" ? FALL_TEXT.unclear : FALL_TEXT.ask[Math.min(ep.asked, FALL_TEXT.ask.length) - 1]!;
    this.show(`${ep.id}:ask:${ep.asked}`, text);
    ep.listenUntil = now + speakMs(text) + this.fcfg.listenMs;
    this.emit({ kind: "asked", episode: ep.id, n: ep.asked, fellAt: ep.fellAt, at: now });
  }

  private show(step: string, text: string): void {
    const ep = this.#ep!;
    ep.sent = { type: "command", id: ep.id, step, text, vision: null, choices: CHOICES, target: null, speak: true };
    this.core.answers.send(ep.sent);
  }

  private ok(now: number): void {
    const ep = this.#ep!;
    this.#ep = null;
    this.#okAt = now;
    this.core.answers.send({ type: "command_clear", id: ep.id });
    const p = ep.paused;
    if (p && OPEN.has(p.run.state) && p.run.sent) {
      const gap = now - p.at;
      p.run.deadline += gap;
      p.run.stepAt += gap;
      p.run.spokeAt = now;
      this.core.answers.send({ ...p.run.sent, speak: true });
    }
    this.emit({ kind: "ok", episode: ep.id, at: now });
  }

  private call(reason: CallCheck, now: number): void {
    const ep = this.#ep!;
    ep.phase = "calling";
    const r = ep.paused?.run;
    const doing = r ? doingOf(r.plan.task) : null;
    ep.paused = null;
    if (r && OPEN.has(r.state)) this.core.steps.finish(r, "failed", EXEC_TEXT.fallStopped, "cancelled");
    this.show(`${ep.id}:call`, FALL_TEXT.calling);
    this.emit({ kind: "call", episode: ep.id, reason, fellAt: ep.fellAt, doing, at: now });
  }
}
```

```ts
  emit(i: number, e: CallEvent): void;

    calls: [], notes: [], hangups: 0, failNext: null,

      if (c.failNext) { const error = c.failNext; c.failNext = null; return { error }; }

      return { note: (t) => { c.notes[i]!.push(t); }, hangup: async () => { c.hangups++; } };
```

```ts
export class FallCall {
  #live: { episode: string; call: LiveCall } | null = null;
  #closed = false;
  constructor(private readonly o: FallCallOptions) {}

  live(): boolean { return this.#live !== null; }
  close(): void { this.#closed = true; }

  onFall(e: FallEvent): void {
    const live = this.#live?.episode === e.episode ? this.#live.call : null;
    switch (e.kind) {
      case "asked":
        this.say(SAY_TEXT.fallAsking, true);
        return this.row(`쓰러짐 확인 질문 ${e.n}`, e.episode, { n: e.n, fell_at_ms: e.fellAt });
      case "heard":
        this.row(`쓰러짐 확인 답 · ${ANSWER_TEXT[e.answer]}`, e.episode, { answer: e.answer, via: e.via, ...(this.o.keep ? { text: e.text } : e.text ? { detail: HEARD_MARK } : {}) });
        return live?.note(NOTE_TEXT[e.answer]);
      case "posture":
        this.row(`쓰러짐 확인 · ${e.now === "up" ? "일어남" : "다시 누움"}`, e.episode, { now: e.now });
        return live?.note(NOTE_TEXT[e.now]);
      case "ok":
        this.say(SAY_TEXT.fallOk, false);
        return this.row("쓰러짐 확인 · 괜찮음", e.episode, {});
      case "call":
        if (live) return live.note(NOTE_TEXT.lying);
        void this.call(e);
    }
  }

  private async call(e: Extract<FallEvent, { kind: "call" }>): Promise<void> {
    this.row(`쓰러짐 확인 · ${REASON_TEXT[e.reason]}`, e.episode, { reason: e.reason });
    this.say(SAY_TEXT.fallCalling, true);
    const { guardian, resident } = this.o.contacts();
    if (!guardian?.phone) return this.end(e.episode, "missing");
    if (!this.o.caller) return this.end(e.episode, "unconnected");
    const facts = callFacts({ world: this.o.world(), resident, check: e.reason, fellAt: e.fellAt, doing: e.doing, tzMinutes: this.o.tzMinutes });
    let last: CallOutcome = "failed";
    for (let attempt = 1; attempt <= this.o.cfg.retries + 1 && !this.#closed; attempt++) {
      if (attempt > 1) {
        this.say(SAY_TEXT.fallRecalling, true);
        await (this.o.sleep ?? ((ms) => new Promise((r) => setTimeout(r, ms))))(this.o.cfg.retryGapMs);
        if (this.#closed) break;
      }
      last = await this.attempt(e, guardian, facts, attempt);
      if (last === "completed") break;
    }
    this.end(e.episode, last);
  }

  private async attempt(e: Extract<FallEvent, { kind: "call" }>, to: ServiceContact, facts: CallFacts, attempt: number): Promise<CallEnd> {
    const id = `${e.episode}:${attempt}`;
    this.row("보호자 전화 · 거는 중", e.episode, { attempt, call_id: id, ...(this.o.keep ? { to } : {}) });
    let done!: (end: CallEnd) => void;
    const ended = new Promise<CallEnd>((r) => (done = r));
    const turns = { guardian: 0, agent: 0 };
    const answeredAt = { ms: null as number | null };
    const opening = openingLine(facts);
    const placed = await this.o.caller!.dial({
      id, to, opening, prompt: guardianPrompt(facts), fallbackSay: opening, ringS: this.o.cfg.ringS, maxMs: this.o.cfg.maxCallMs, keepText: this.o.keep,
      onEvent: (ev: CallEvent) => {
        if (ev.kind === "ringing") this.row("보호자 전화 · 울림", e.episode, { ms_from_fall: ev.atMs - e.fellAt });
        else if (ev.kind === "answered") {
          answeredAt.ms = ev.atMs;
          this.row("보호자 전화 · 받음", e.episode, { ms_from_fall: ev.atMs - e.fellAt });
          this.say(SAY_TEXT.fallTalking, true);
          this.o.phase(e.episode, "talking");
        } else if (ev.kind === "first_word") this.row("보호자 전화 · 첫마디", e.episode, { first_word_ms: ev.atMs - e.fellAt });
        else if (ev.kind === "turn") turns[ev.who]++;
        else {
          this.#live = null;
          const seconds = answeredAt.ms === null ? 0 : Math.round((ev.atMs - answeredAt.ms) / 1000);
          this.row(`보호자 전화 · ${OUTCOME_TEXT[ev.end]}`, e.episode, { outcome: ev.end, seconds, guardian_turns: turns.guardian, agent_turns: turns.agent, ...(ev.error ? { error: ev.error } : {}) });
          done(ev.end);
        }
      },
    });
    if ("error" in placed) {
      this.row("보호자 전화 · 실패", e.episode, { outcome: "failed", error: placed.error });
      return "failed";
    }
    this.#live = { episode: e.episode, call: placed };
    return ended;
  }

  private end(episode: string, outcome: CallOutcome): void {
    const t = END_TEXT[outcome];
    if (outcome === "missing" || outcome === "unconnected") this.row(`보호자 전화 · ${OUTCOME_TEXT[outcome]}`, episode, { outcome });
    this.say(t.say, false);
    this.o.phoneSay(t.phone);
    this.o.phase(episode, "ended");
  }

  private say(text: string, live: boolean): void { this.o.say({ text, live }); }
  private row(text: string, subject: string, data: Record<string, unknown>): void { this.o.record({ at: this.o.clock.now(), text, subject, data }); }
}
```

```ts
import { WebSocketServer, type WebSocket } from "ws";

export interface FakeRealtimeSession { auth: string | undefined; url: string; events: any[]; ws: WebSocket }

  url: string; sessions: FakeRealtimeSession[];

export async function startFakeRealtime(o: { reply?: (said: string, instructions: string) => string | { end: string }; refuse?: boolean } = {}): Promise<FakeRealtime> {
  // refuse: 연결 올리기를 401로 거절한다(실시간 음성 연결 실패)

    const id = `resp_${++n}`;
    s.ws.send(JSON.stringify({ type: "response.created", response: { id } }));
    for (const part of [text.slice(0, 5), text.slice(5)]) if (part) s.ws.send(JSON.stringify({ type: "response.output_audio.delta", response_id: id, delta: b64(part) }));
    s.ws.send(JSON.stringify({ type: "response.output_audio.done", response_id: id }));
    s.ws.send(JSON.stringify({ type: "response.output_audio_transcript.done", response_id: id, transcript: text }));
    if (end) s.ws.send(JSON.stringify({ type: "response.function_call_arguments.done", response_id: id, name: "end_call", call_id: "c1", arguments: "{}" }));
    s.ws.send(JSON.stringify({ type: "response.done", response: { id } }));
  };
  wss.on("connection", (ws, req) => {
    const s: FakeRealtimeSession = { auth: req.headers.authorization, url: req.url ?? "", events: [], ws };
    sessions.push(s);
    ws.on("message", (d) => {
      const e = JSON.parse(String(d));
      s.events.push(e);
      if (e.type === "response.create") {
        const said = /그대로 한 번 말한다: (.*)$/s.exec(e.response?.instructions ?? "")?.[1] ?? "새 사실을 알렸어요.";
        speak(s, said);
      }
    });
  });
  const port = (wss.address() as AddressInfo).port;
  return {
    url: `ws://127.0.0.1:${port}/v1/realtime`, sessions,
    guardianSays(i, text) {
      const s = sessions[i]!;
      s.ws.send(JSON.stringify({ type: "input_audio_buffer.speech_started" }));
      s.ws.send(JSON.stringify({ type: "input_audio_buffer.speech_stopped" }));
      const update = s.events.find((e) => e.type === "session.update");

    },
    close: () => new Promise<void>((r) => { for (const c of wss.clients) c.terminate(); wss.close(() => r()); }),
  };
}
```

```ts
// src/infer/voice-call/realtime.ts
// 외부 API 통로: OpenAI 실시간 음성(CALL_REALTIME_URL, 기본 wss://api.openai.com/v1/realtime) 세션 하나. 전화 소리 G.711 μ-law를 그대로 주고받는다.
// 열자마자 지시문·목소리·말 끝 판정(server VAD 0.5초)·도구 end_call을 맞추고 첫마디를 만들기 시작한다(받기 전에 만들어 두어 받자마자 보낸다).
// 받아쓰기는 keepText(KEEP_HEARD_TEXT=1)일 때만 켠다. 새 사실은 [새 사실] 시스템 메시지로 넣고, 응답 중·보호자가 말하는 중이면 끝난 뒤 응답을 만든다.
import WebSocket from "ws";
import { headWithin } from "../../shared/cut.js";

export interface RealtimeOptions { url: string; key: string; model: string; voice: string; prompt: string; opening: string; keepText: boolean; openTimeoutMs?: number }

export function sessionConfig(o: RealtimeOptions): Record<string, unknown> {
  return {
    type: "realtime", model: o.model, instructions: o.prompt,
    audio: {
      input: { format: { type: "audio/pcmu" }, turn_detection: { type: "server_vad", silence_duration_ms: 500 }, ...(o.keepText ? { transcription: { model: "gpt-4o-mini-transcribe", language: "ko" } } : {}) },
      output: { format: { type: "audio/pcmu" }, voice: o.voice },
    },
    tools: [{ type: "function", name: "end_call", description: "보호자와 통화를 끝낸다. 마무리 인사를 한 뒤에 부른다.", parameters: { type: "object", properties: {} } }],
    tool_choice: "auto",
  };
}

export class RealtimeSession {
  #buffer: string[] = [];
  #audio: ((b64: string) => void) | null = null;
  #cbs = { done: [] as (() => void)[], speech: [] as (() => void)[], turn: [] as ((w: "guardian" | "agent", t?: string) => void)[], end: [] as (() => void)[], error: [] as ((m: string) => void)[] };
  #responding = false;
  #speaking = false;
  #pending = false;
  #closed = false;

  private constructor(private readonly ws: WebSocket, private readonly o: RealtimeOptions) {
    ws.on("message", (d) => this.on(JSON.parse(String(d)) as Record<string, any>));
    ws.on("close", () => { if (!this.#closed) this.#cbs.error.forEach((f) => f("실시간 음성 연결이 끊김")); });
  }

  static async open(o: RealtimeOptions): Promise<RealtimeSession> {
    const ws = new WebSocket(`${o.url}?model=${encodeURIComponent(o.model)}`, { headers: { authorization: `Bearer ${o.key}` } });
    await new Promise<void>((resolve, reject) => {
      const t = setTimeout(() => { ws.terminate(); reject(new Error("실시간 음성 연결 제한 시간")); }, o.openTimeoutMs ?? 5000);
      ws.once("open", () => { clearTimeout(t); resolve(); });
      ws.once("error", (e) => { clearTimeout(t); reject(new Error(`실시간 음성 연결 실패: ${headWithin(e.message, 120)}`)); });
      ws.once("close", (code) => { clearTimeout(t); reject(new Error(`실시간 음성 연결이 닫힘(${code})`)); });
    });
    const s = new RealtimeSession(ws, o);
    s.send({ type: "session.update", session: sessionConfig(o) });
    s.respond(`다음 문장을 바꾸지 말고 그대로 한 번 말한다: ${o.opening}`);
    return s;
  }

  onAudio(cb: (b64: string) => void): void { for (const b of this.#buffer.splice(0)) cb(b); this.#audio = cb; }
  onAudioDone(cb: () => void): void { this.#cbs.done.push(cb); }
  onSpeechStart(cb: () => void): void { this.#cbs.speech.push(cb); }
  onTurn(cb: (who: "guardian" | "agent", text?: string) => void): void { this.#cbs.turn.push(cb); }
  onEndCall(cb: () => void): void { this.#cbs.end.push(cb); }
  onError(cb: (message: string) => void): void { this.#cbs.error.push(cb); }
  append(b64: string): void { this.send({ type: "input_audio_buffer.append", audio: b64 }); }
  note(text: string): void {
    this.send({ type: "conversation.item.create", item: { type: "message", role: "system", content: [{ type: "input_text", text: `[새 사실] ${text}` }] } });
    if (this.#responding || this.#speaking) this.#pending = true;
    else this.respond("[새 사실]을 보호자에게 한 문장으로 바로 알린다.");
  }
  close(): void { this.#closed = true; this.ws.close(); }

  private respond(instructions: string): void { this.#responding = true; this.send({ type: "response.create", response: { instructions } }); }
  private send(e: Record<string, unknown>): void { if (this.ws.readyState === WebSocket.OPEN) this.ws.send(JSON.stringify(e)); }
  private flushPending(): void {
    if (!this.#pending || this.#responding || this.#speaking) return;
    this.#pending = false;
    this.respond("[새 사실]을 보호자에게 한 문장으로 바로 알린다.");
  }

  private on(e: Record<string, any>): void {
    switch (e.type) {
      case "response.created": this.#responding = true; return;
      case "response.output_audio.delta": return this.#audio ? this.#audio(e.delta) : void this.#buffer.push(e.delta);
      case "response.output_audio.done": return this.#cbs.done.forEach((f) => f());
      case "response.output_audio_transcript.done": return this.#cbs.turn.forEach((f) => f("agent", e.transcript));
      case "input_audio_buffer.speech_started": this.#speaking = true; return this.#cbs.speech.forEach((f) => f());
      case "input_audio_buffer.speech_stopped":
        this.#speaking = false;
        if (!this.o.keepText) this.#cbs.turn.forEach((f) => f("guardian"));
        return;
      case "conversation.item.input_audio_transcription.completed": return this.#cbs.turn.forEach((f) => f("guardian", e.transcript));
      case "response.function_call_arguments.done": if (e.name === "end_call") this.#cbs.end.forEach((f) => f()); return;
      case "response.done": this.#responding = false; return this.flushPending();
      case "error": return this.#cbs.error.forEach((f) => f(headWithin(String(e.error?.message ?? "실시간 음성 오류"), 200)));
    }
  }
}
```

- 흐름(`dial`): 토큰(24바이트 hex) → `create`(To `e164`, From, Twiml, StatusCallback `<공개>/call/status/<토큰>`, Timeout `ringS`, 상태 알림 initiated·ringing·answered·completed) → 접수되면 `RealtimeSession.open`(울리는 동안 첫마디를 만든다). 상태 알림: ringing → `ringing`, in-progress → `answered`(최대 통화 타이머 시작), completed(받은 뒤) → `ended completed`, busy → `busy`, no-answer → `no_answer`, failed·canceled·받기 전 completed → `failed`. 스트림 `start` → 세션이 있으면 `onAudio`로 소리를 `media`로 보내고 첫 조각에서 `first_word`, 보호자 말 시작이면 `clear`, `media` → `append`. 받은 뒤 3초 안에 세션이 없거나 세션이 오류면 스트림을 닫는다(TwiML이 이어서 `<Say>`로 사실을 읽는다, `ended`의 `error: "실시간 음성 연결 실패"`). `end_call` → 소리가 끝난 뒤 `mark` `end`를 보내고 Twilio가 그 `mark`를 돌려주면 `hangup`. 최대 통화 시간이면 「통화 시간이 다 됐어요. 마무리 인사를 하고 end_call을 부르세요.」 새 사실을 넣고 15초 뒤 `hangup`. 받기 전에 들어온 새 사실은 세션에 넣어 두고 첫마디 소리가 끝난 뒤 응답을 만든다.
- 상태 알림은 `X-Twilio-Signature`를 `<CALL_PUBLIC_URL>/call/status/<토큰>`과 받은 폼으로 맞춰 본다. 틀리면 403, 모르는 토큰은 404. 스트림은 살아 있는 토큰에 한 번만 받는다.

```ts
// 시험용 Twilio(TWILIO_API_URL 자리의 가짜 HTTP 서버): Calls.json을 받아 기록하고, 정한 받는 방법대로 서명한 상태 알림을 보내고,
// 받음이면 TwiML의 Stream 주소로 WebSocket을 열어 connected·start·조용한 media를 보낸다. 받은 media·mark·clear를 기록하고 mark는 그대로 돌려준다(다 들려줌).

import WebSocket from "ws";
import { twilioSignature } from "../../src/infer/voice-call/twilio.js";

export interface FakeTwilioCall {
  sid: string; form: URLSearchParams; streamUrl: string; callParam: string | null;
  media: string[]; marks: string[]; clears: number; hungUp: boolean; fallbackSaid: boolean; statuses: string[]; ws: WebSocket | null;
}
export interface FakeTwilio {
  url: string; calls: FakeTwilioCall[];
  /** 다음 전화들의 받는 방법(앞에서부터 하나씩, 비면 human). fail은 Calls.json에 400. */
  next: ("human" | "no-answer" | "busy" | "fail")[];
  ringMs: number;
  close(): Promise<void>;
}

export async function startFakeTwilio(o: { authToken: string; ringMs?: number }): Promise<FakeTwilio> {
  const calls: FakeTwilioCall[] = [];
  const out: FakeTwilio = { url: "", calls, next: [], ringMs: o.ringMs ?? 100, close: async () => {} };
  const notify = async (c: FakeTwilioCall, status: string) => {
    c.statuses.push(status);
    const params = { CallSid: c.sid, CallStatus: status };
    const url = c.form.get("StatusCallback")!;
    await fetch(url, { method: "POST", headers: { "content-type": "application/x-www-form-urlencoded", "x-twilio-signature": twilioSignature(o.authToken, url, params) }, body: new URLSearchParams(params) }).catch(() => {});
  };
  const answer = async (c: FakeTwilioCall) => {
    await notify(c, "in-progress");
    const ws = new WebSocket(c.streamUrl);
    c.ws = ws;
    let timer: NodeJS.Timeout | undefined;
    ws.on("open", () => {
      ws.send(JSON.stringify({ event: "connected" }));
      ws.send(JSON.stringify({ event: "start", start: { streamSid: "MZ1", callSid: c.sid, customParameters: { call: c.callParam } } }));
      timer = setInterval(() => ws.send(JSON.stringify({ event: "media", media: { payload: Buffer.alloc(160, 0xff).toString("base64") } })), 20);
    });
    ws.on("message", (d) => {
      const m = JSON.parse(String(d));
      if (m.event === "media") c.media.push(m.media.payload);
      if (m.event === "clear") c.clears++;
      if (m.event === "mark") { c.marks.push(m.mark.name); ws.send(JSON.stringify({ event: "mark", mark: m.mark })); }
    });
    ws.on("close", () => { clearInterval(timer); if (!c.hungUp) { c.fallbackSaid = true; void notify(c, "completed"); } });
  };
  const server = createServer(async (req, res) => {
    let raw = "";
    for await (const ch of req) raw += ch;
    const form = new URLSearchParams(raw);
    const hang = /\/Calls\/(CA\d+)\.json$/.exec(req.url ?? "");
    if (hang) {
      const c = calls.find((x) => x.sid === hang[1])!;
      c.hungUp = true;
      c.ws?.send(JSON.stringify({ event: "stop" }));
      c.ws?.close();
      res.writeHead(200).end("{}");
      void notify(c, "completed");
      return;
    }
    const how = out.next.shift() ?? "human";
    if (how === "fail") return void res.writeHead(400, { "content-type": "application/json" }).end(JSON.stringify({ message: "시험 실패" }));
    const tw = form.get("Twiml") ?? "";
    const c: FakeTwilioCall = { sid: `CA${calls.length + 1}`, form, streamUrl: /<Stream url="([^"]+)"/.exec(tw)?.[1]?.replace(/&amp;/g, "&") ?? "", callParam: /<Parameter name="call" value="([^"]+)"/.exec(tw)?.[1] ?? null,
      media: [], marks: [], clears: 0, hungUp: false, fallbackSaid: false, statuses: [], ws: null };
    calls.push(c);
    res.writeHead(201, { "content-type": "application/json" }).end(JSON.stringify({ sid: c.sid, status: "queued" }));
    await notify(c, "ringing");
    await new Promise((r) => setTimeout(r, out.ringMs));
    if (how === "human") await answer(c);
    else await notify(c, how);
  });
  const addr: AddressInfo = await listenRetry(server, 0, "127.0.0.1");
  out.url = `http://127.0.0.1:${addr.port}`;
  out.close = () => new Promise<void>((r) => { for (const c of calls) c.ws?.terminate(); server.closeAllConnections(); server.close(() => r()); });
  return out;
}

/** 비어 있는 로컬 포트 하나(CALL_PORT·CALL_PUBLIC_URL을 미리 맞출 때). */
export async function freePort(): Promise<number> {
  const s = createServer();
  const a: AddressInfo = await listenRetry(s, 0, "127.0.0.1");
  await new Promise<void>((r) => s.close(() => r()));
  return a.port;
}
```

```ts
export function voiceCallFrom(env: Record<string, string | undefined>): VoiceCallConfig | null {
```

```ts
import { createHmac, timingSafeEqual } from "node:crypto";
import { headWithin } from "../../shared/cut.js";
import type { VoiceCallConfig } from "./config.js";

export function e164(phone: string): string {
  const d = phone.replace(/[\s-]/g, "");
  return d.startsWith("+") ? d : `+82${d.replace(/^0/, "")}`;
}
const esc = (s: string) => s.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;").replace(/"/g, "&quot;");
export function twiml(o: { streamUrl: string; callId: string; fallbackSay: string }): string {
  return `<?xml version="1.0" encoding="UTF-8"?><Response><Connect><Stream url="${esc(o.streamUrl)}"><Parameter name="call" value="${esc(o.callId)}"/></Stream></Connect>`
    + `<Say language="ko-KR" voice="Polly.Seoyeon">${esc(o.fallbackSay)}</Say></Response>`;
}
export function twilioSignature(authToken: string, url: string, params: Record<string, string>): string {
  return createHmac("sha1", authToken).update(url + Object.keys(params).sort().map((k) => k + params[k]).join(""), "utf8").digest("base64");
}
export function signatureOk(authToken: string, url: string, params: Record<string, string>, got: string | undefined): boolean {
  const want = Buffer.from(twilioSignature(authToken, url, params));
  const g = Buffer.from(got ?? "");
  return g.length === want.length && timingSafeEqual(g, want);
}

export class TwilioRest {
  constructor(private readonly c: Pick<VoiceCallConfig, "accountSid" | "authToken" | "apiUrl">) {}

    for (const ev of ["initiated", "ringing", "answered", "completed"]) body.append("StatusCallbackEvent", ev);

      return res.ok && j.sid ? { sid: j.sid } : { error: `Twilio HTTP ${res.status}${j.message ? `: ${headWithin(j.message, 120)}` : ""}` };
```

```ts
// 외부 API 통로: 보호자 전화 한 통 = Twilio 걸기 + 실시간 음성 세션 + 전화 소리 잇기(Media Streams). 공개 듣기 자리(src/server/call-port.ts)의 두 경로를 받는다.
// 흐름·사건은 docs/superpowers/plans/2026-11-18-fall-call.md Task 5. 이 파일은 도메인을 가져오지 않는다(기반층).
import { randomBytes } from "node:crypto";
import type { IncomingMessage, ServerResponse } from "node:http";
import type { Duplex } from "node:stream";
import { WebSocketServer, type WebSocket } from "ws";
import type { CallEnd, LiveCall, DialCall, VoiceCaller } from "../../contract/call.js";
import type { VoiceCallConfig } from "./config.js";
import { RealtimeSession } from "./realtime.js";
import { TwilioRest, e164, signatureOk, twiml } from "./twilio.js";

/** 받은 뒤 실시간 세션을 기다리는 시간. 넘으면 스트림을 닫아 사실 안내(TwiML <Say>)로 넘긴다. */
const SESSION_WAIT_MS = 3000;
/** 최대 통화 시간 뒤 마무리를 기다리는 시간. */
const WRAP_MS = 15_000;

interface Live {
  c: DialCall; token: string; sid: string | null; session: RealtimeSession | null; sessionError: string | null;
  stream: WebSocket | null; streamSid: string | null; answered: boolean; ended: boolean; firstWord: boolean; timers: NodeJS.Timeout[]; error?: string;
}

export class TwilioRealtimeCaller implements VoiceCaller {
  readonly #calls = new Map<string, Live>();
  readonly #wss = new WebSocketServer({ noServer: true });
  readonly #rest: TwilioRest;
  constructor(readonly cfg: VoiceCallConfig) { this.#rest = new TwilioRest(cfg); }

  async dial(c: DialCall): Promise<LiveCall | { error: string }> {
    if (!c.to.phone) return { error: "보호자 번호 없음" };
    const token = randomBytes(24).toString("hex");
    const live: Live = { c, token, sid: null, session: null, sessionError: null, stream: null, streamSid: null, answered: false, ended: false, firstWord: false, timers: [] };
    this.#calls.set(token, live);
    const streamUrl = `${this.cfg.publicUrl.replace(/^http/, "ws")}/call/stream/${token}`;
    const r = await this.#rest.create({ to: e164(c.to.phone), from: this.cfg.from, twiml: twiml({ streamUrl, callId: c.id, fallbackSay: c.fallbackSay }), statusUrl: `${this.cfg.publicUrl}/call/status/${token}`, timeoutS: c.ringS });
    if ("error" in r) { this.#calls.delete(token); return r; }
    live.sid = r.sid;
    RealtimeSession.open({ url: this.cfg.realtimeUrl, key: this.cfg.openaiKey, model: this.cfg.realtimeModel, voice: this.cfg.voice, prompt: c.prompt, opening: c.opening, keepText: c.keepText })
      .then((s) => { if (live.ended) return s.close(); live.session = s; this.wire(live); }, (e: Error) => { live.sessionError = e.message; });
    return { note: (t) => live.session?.note(t), hangup: () => this.hangup(live) };
  }
  /** 상태 알림(POST /call/status/<토큰>): 서명이 맞을 때만 사건으로 바꾼다. */
  async handleStatus(req: IncomingMessage, res: ServerResponse): Promise<void> {
    const token = (req.url ?? "").split("/").pop() ?? "";
    const live = this.#calls.get(token);
    let raw = "";
    for await (const ch of req) raw += ch;
    if (!live) return void res.writeHead(404).end();
    const form = Object.fromEntries(new URLSearchParams(raw));
    if (!signatureOk(this.cfg.authToken, `${this.cfg.publicUrl}/call/status/${token}`, form, req.headers["x-twilio-signature"] as string | undefined)) return void res.writeHead(403).end();
    res.writeHead(204).end();
    const at = Date.now();
    switch (form.CallStatus) {
      case "ringing": return live.c.onEvent({ kind: "ringing", atMs: at });
      case "in-progress":
        if (live.answered) return;
        live.answered = true;
        live.c.onEvent({ kind: "answered", atMs: at });
        live.timers.push(setTimeout(() => {
          live.session?.note("통화 시간이 다 됐어요. 마무리 인사를 하고 end_call을 부르세요.");
          live.timers.push(setTimeout(() => void this.hangup(live), WRAP_MS));
        }, live.c.maxMs));
        return;
      case "completed": return this.end(live, live.answered ? "completed" : "failed", live.error);
      case "busy": return this.end(live, "busy");
      case "no-answer": return this.end(live, "no_answer");
      case "failed": case "canceled": return this.end(live, "failed", `Twilio ${form.CallStatus}`);
    }
  }

  /** 전화 소리(WS /call/stream/<토큰>): 살아 있는 토큰에 한 번만 받는다. */
  handleUpgrade(req: IncomingMessage, socket: Duplex, head: Buffer): void {
    const live = this.#calls.get((req.url ?? "").split("/").pop() ?? "");
    if (!live || live.stream) return void socket.destroy();
    this.#wss.handleUpgrade(req, socket, head, (ws) => {
      live.stream = ws;
      ws.on("message", (d) => {
        const m = JSON.parse(String(d)) as { event: string; start?: { streamSid: string }; media?: { payload: string }; mark?: { name: string } };
        if (m.event === "start") {
          live.streamSid = m.start!.streamSid;
          if (live.session) return this.wire(live);
          if (live.sessionError) return this.fallback(live);
          live.timers.push(setTimeout(() => (live.session ? undefined : this.fallback(live)), SESSION_WAIT_MS));
        } else if (m.event === "media") live.session?.append(m.media!.payload);
        else if (m.event === "mark" && m.mark?.name === "end") void this.hangup(live);
      });
    });
  }

  /** 세션 ↔ 전화 소리. place의 세션 준비(then)와 스트림 start 가운데 늦은 쪽이 부른다(둘 다 있을 때 한 번). */
  private wire(live: Live): void {
    const s = live.session, ws = live.stream;
    if (!s || !ws || !live.streamSid || (live as { wired?: true }).wired) return;
    (live as { wired?: true }).wired = true;
    const send = (m: Record<string, unknown>) => ws.send(JSON.stringify({ ...m, streamSid: live.streamSid }));
    let ending = false, playing = false;
    s.onAudio((b64) => {
      playing = true;
      if (!live.firstWord) { live.firstWord = true; live.c.onEvent({ kind: "first_word", atMs: Date.now() }); }
      send({ event: "media", media: { payload: b64 } });
    });
    s.onAudioDone(() => { playing = false; if (ending) send({ event: "mark", mark: { name: "end" } }); });
    s.onSpeechStart(() => send({ event: "clear" }));
    s.onTurn((who, text) => live.c.onEvent({ kind: "turn", who, atMs: Date.now(), ...(text ? { text } : {}) }));
    s.onEndCall(() => { ending = true; if (!playing) send({ event: "mark", mark: { name: "end" } }); });
    s.onError((msg) => { live.error = msg; this.fallback(live); });
  }

  /** 실시간 음성이 안 되면 스트림을 닫는다: TwiML이 이어서 <Say>로 사실 안내를 읽는다. */
  private fallback(live: Live): void {
    live.error ??= "실시간 음성 연결 실패";
    live.session?.close();
    live.stream?.close();
  }

  private async hangup(live: Live): Promise<void> {
    if (live.sid && !live.ended) await this.#rest.hangup(live.sid);
  }

  /** 한 번만: 타이머·세션을 닫고 지운 뒤 ended 사건. */
  private end(live: Live, end: CallEnd, error?: string): void {
    if (live.ended) return;
    live.ended = true;
    for (const t of live.timers) clearTimeout(t);
    live.session?.close();
    this.#calls.delete(live.token);
    live.c.onEvent({ kind: "ended", end, atMs: Date.now(), ...(error ? { error } : {}) });
  }

  /** 서버를 닫는다: 세션·스트림을 닫고(통화는 Twilio가 사실 안내로 마무리) 듣기 자리를 닫는다. */
  async close(): Promise<void> {
    for (const live of this.#calls.values()) { live.session?.close(); live.stream?.close(); }
    this.#wss.close();
  }
}
```

```ts
// 전화 전용 포트(CALL_PORT, 127.0.0.1): Twilio가 닿는 두 경로만 둔다. POST /call/status/<토큰>(상태 알림), WS /call/stream/<토큰>(전화 소리). 그 밖은 404·끊기.
// 밖에서는 이 포트만 공개 주소로 연다(Tailscale Funnel). 대시보드·폰 포트는 열지 않는다.
import { createServer } from "node:http";
import type { AddressInfo } from "node:net";
import type { TwilioRealtimeCaller } from "../infer/voice-call/caller.js";
import { listenRetry } from "../shared/net.js";

export async function openCallPort(caller: TwilioRealtimeCaller, port: number, host = "127.0.0.1"): Promise<{ port: number; close(): Promise<void> }> {
  const server = createServer((req, res) => {
    if (req.method === "POST" && /^\/call\/status\/[0-9a-f]+$/.test(req.url ?? "")) return void caller.handleStatus(req, res);
    res.writeHead(404).end();
  });
  server.on("upgrade", (req, socket, head) => (/^\/call\/stream\/[0-9a-f]+$/.test(req.url ?? "") ? caller.handleUpgrade(req, socket, head) : socket.destroy()));
  const a: AddressInfo = await listenRetry(server, port, host);
  return { port: a.port, close: () => new Promise<void>((r) => { server.closeAllConnections(); server.close(() => r()); }) };
}
```
